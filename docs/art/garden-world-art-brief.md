# 小岛花园 · 即梦出图包

一共 **3 张图**。第 1 张最重要，值得多生成几轮挑最好的；后两张各生成一轮就够。

要用到的参考图都在仓库 `art/guide/` 里（我也会直接发给你）：

| 文件 | 用途 |
|---|---|
| `world-blockout.png` | **白模**：整座岛的布局，路、小溪、每栋建筑的位置都按游戏里的格子摆好。第 1 张图照着它画 |
| `world-blockout-labels.png` | 同一张白模加了区域名字，给你看懂布局用，**不要**上传给即梦（它会把字也画进去） |
| `style-ref.jpg` | **画风参考**：现在游戏里扭蛋物件和小动物的样子，岛要画成同一种风格，摆上去才不突兀 |

## 通用设置

- 用即梦的「图片生成」，模型选最新的（图片 4.0 或更新）
- 分辨率选**最高**（有 4K 选 4K，没有就选最大的），下载**原图**，不要截图
- 一次出 4 张，挑一张最好的；不满意就再来一轮
- 生成好以后把选中的图打包成 zip 发给我，文件名随意，告诉我哪张是哪张就行

## 第 1 张 · 整岛大图（最重要）

- **参考图**：上传 `world-blockout.png`（第 1 张）和 `style-ref.jpg`（第 2 张）。如果有「参考强度 / 相似度」之类的选项，调到偏高，让布局别跑偏
- **比例**：3:4（竖图）
- **怎么挑**：先看布局有没有跟白模对上，尤其是路的走向、小院、荷塘、喷泉的位置；然后再看漂不漂亮。可以多挑一两张备选一起发我

**提示词（整段复制）：**

```
参考图1是一座小岛的白模布局，参考图2是画风参考。请把参考图1重绘成一张精品手游的主城场景原画。
严格保持参考图1的构图、等距俯视角度、小岛轮廓、每条小路的走向，以及每栋建筑、每个区域的位置和大小，不要移动、增加或删掉道路和建筑。
画风参考图2：可爱的3D卡通渲染，圆润饱满的粘土质感，温暖明亮的色彩，柔和的左上方光照，细腻的环境光遮蔽，精致、干净、细节丰富。

画面内容：一座中式养生花园小岛，四周是清澈的蓝绿色大海和白色浪花，岛边是层层的岩石悬崖和浅色沙滩。
最上方：一座太湖石假山，山上挂着一道小瀑布落进清澈的水潭；假山前是一片翠绿竹林和一座红柱灰瓦的小六角亭。
中上方：抬高一层的石砌台地上，一座白墙黛瓦的两进中式小院，飞檐翘角，正面一个圆形月亮门，门口挂两盏红灯笼，几级石阶下到中间。
左上方：果园，几排挂满橘子、桃子、柿子的果树，旁边一个挂满紫葡萄的葡萄架。
右上方：温泉小筑，冒着热气的岩石温泉池，旁边一间日晒木色的小木屋、一盏石灯笼和一段竹篱笆。
正中间：一大片平整干净的嫩绿草坪，四周围着修剪整齐的矮绿篱，草坪中间什么都不要放，保持空旷平整。
左中：动物小院，木栅栏围起来的草地，里面有红顶鸡舍、小兔窝、小木屋、金黄的草垛和木食槽。
右中：荷塘水榭，一大片荷塘，水面铺满荷叶和粉色荷花，一座红栏杆的九曲木桥穿过水面，通到建在水上的小亭子，岸边有鹅卵石滩和几块山石。一条小溪从瀑布的水潭流下来，经过一座石拱桥流进荷塘，再经过一架木水车，从岛边化作小瀑布落进大海。
左下方：菜园药圃，一畦畦整齐的菜地种着白菜、萝卜、南瓜藤，竹篱笆、挂着葫芦的瓜架，还有几小块开着菊花和枸杞的药草圃。
中下偏右：花圃，一片片盛开的牡丹、月季、绣球花坛，一座粉色玫瑰花拱门，一条开满紫藤的木长廊，一张木长椅。
中间偏左：一棵枝叶繁茂的大古树，树枝上挂着一架木秋千。
最下方：一个圆形石板广场，中央一座汉白玉三层喷泉在喷水，四周是花坛和红灯笼；广场前一道石阶下到海边的木栈道码头，码头边停着一艘中式画舫。
弯弯曲曲的浅色石板路把各处连起来，路边点缀圆圆的矮灌木、小花丛和红灯笼，草地上散落着小野花，岛的边缘一圈是各种树木和山石。整个小岛郁郁葱葱、精致奢华、色彩明快。

要求：高清，细节丰富，画面里没有文字、没有界面按钮、没有人物、没有小动物、没有边框，小岛占满画面，四周露出一圈大海。
```

## 第 2 张 · 云雾（盖住还没修整的地方）

- **参考图**：上传 `style-ref.jpg`
- **比例**：1:1

```
一组可爱的卡通云朵游戏素材，参考图的3D卡通渲染画风。6朵形状、大小都不一样的蓬松白云：有扁长的、有圆滚滚的、有三四团连在一起的，云朵洁白柔软，底部带一点淡淡的蓝灰色阴影。6朵云整齐分开排列，彼此不重叠、不相连。
背景是纯黑色，干净平整，没有任何渐变和杂物。没有文字。
```

背景一定要是**纯黑**，我靠它把云朵干净地抠出来。

## 第 3 张 · 木牌和按钮图标

- **参考图**：上传 `style-ref.jpg`
- **比例**：3:2

```
一组手游界面图标素材，参考图的3D卡通渲染画风，圆润可爱，色彩明亮。6个物件整齐排成2行3列，彼此分开，不重叠：
1. 一块立在草地上的中式木牌：一根木桩上钉着一块横的长方形空白木板，木板上不要写任何字；
2. 一只编织竹篮，里面装着花草和小果子；
3. 一本红色顶边的翻页台历，页面是空白的，不要写字；
4. 一座小小的白墙黛瓦中式房子；
5. 一台圆润可爱的复古照相机；
6. 一团金色闪光的庆祝彩带和小星星。
背景是纯洋红色（#FF00FF），干净平整，没有渐变和阴影。没有文字。
```

背景用**纯洋红色**也是为了好抠图；这些图标里没有洋红色，抠起来不会伤到物件。

## 我这边怎么用

- 第 1 张对齐游戏格子后当整座岛的底图：能走的路、能摆东西的草地我按画面标好；小动物、扭蛋物件摆在上面，脚下加阴影
- 第 2 张抠成云朵，盖在还没修整的区域上；修整时云朵往两边飘散
- 第 3 张：1 是修整木牌，2～5 换掉背包、日历、回家、拍照按钮的图标，6 是修整成功时的庆祝效果
- 大图放云存储，不占小程序 2MB 的包
