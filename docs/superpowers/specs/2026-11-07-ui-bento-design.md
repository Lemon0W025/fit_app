# 界面第二版：「便当盒」风格（2026-11-07）

取代同一天的 `2026-11-07-ui-starbucks-style-design.md`。用户看了 Starbucks 那版说「太简单、太 AI 感，就是一些矩形叠在一起，没有设计感」，发来一张参考图（CaloriCam 一类的健康 App：浅灰底、大圆角卡片、超大加粗数字、圆形图标小徽章、粉黄蓝的粗进度条、柠檬绿点缀、底栏中间一个黑色圆形拍照按钮），照这个方向重做。

## 和上一版差在哪

上一版只换了颜色，版面还是「标题 + 一行行字」。这一版改的是版面语言：

- **每张卡都有「头」**：左边一个 72rpx 的图标小圆章（`.chip-icon`，线性图标），中间标题，右边一句话或箭头（`.card-head`）
- **数字当主角**：饭点时间 148rpx、今天吃了百分之几 132rpx、这顿多少千卡 128rpx，用几何感的字（`--font-num`：iPhone 上是 Avenir Next）
- **数据用图形说**：三大营养素是粗胶囊进度条（`.bar` / `.bar-fill`，碳水粉、蛋白质蓝、脂肪黄），热量是粗圆环 + 中间白色圆片
- **一页一个黑色主角**：首页「下一顿」是黑卡，按钮柠檬绿；过点了换暖橙
- **底栏中间一个黑色大圆钮直接拍照**（自定义底栏），拍照永远一下就到

## 色板（`app.wxss` 的 `page` 变量）

| 变量 | 值 | 管什么 |
|---|---|---|
| `--bg` / `--card` / `--chip` | `#f3f4f0` / 白 / `#f1f2ee` | 页面底 / 卡片 / 图标小圆章、进度条底、输入框 |
| `--ink` | `#17191c` | 字、主按钮、黑卡、选中的胶囊 |
| `--lime` / `--lime-soft` / `--lime-deep` / `--lime-ink` | `#c4ef5a` / `#e3f6b5` / `#8ac226` / `#3f5c00` | 黑卡上的按钮、选中的 tab / 「今天吃了」卡、圆环 / 浅色底上的绿字 |
| `--bean*` | `#f5a524` 一套 | 暖豆、准时、纪念章（奖励） |
| `--peach*` | `#ffb37a` 一套 | 过点了 |
| `--carbs*` / `--fat*` / `--protein*` | 粉 / 黄 / 蓝 | 三大营养素 |
| `--red` | `#d93a40` | 删除、超了 |

上一版的变量名（`--primary`、`--brand`、`--house`、`--gold*`……）都留着、指到新的上面，没改到的地方也不会坏。

## 组件

- `.card`：40rpx 圆角、很淡的往下散的阴影；`.card-lime`（柠檬绿）、`.card-ink`（黑）、`.card-peach`、`.reward-card`（暖豆橙）
- `.card-head` + `.chip-icon` + `.card-head-title` + `.card-head-more` / `.card-head-go`
- `.num` 大数字，`.num-unit` 跟在后面的单位
- `.bar` / `.bar-fill`（宽度直接给 `style="width: N%"`，第一次出来从左边滑进来）
- 按钮：`btn-primary` 黑色胶囊；`btn-lime` / `btn-on-dark` 柠檬绿（黑卡上）；`btn-peach`；`btn-plain` 浅灰胶囊；`.btn-icon` 按钮里的图标；`.round-btn` 白色圆钮；`.pill` 白色胶囊
- `.chip` 选项小块：浅灰，选中黑底白字
- `.macros` 营养素三块：蓝 / 粉 / 黄的浅色块，数字用各自的深色
- 印章：绿 = 柠檬绿、黄、红是营养素的黄和粉，准时一圈暖豆橙
- 组件：分段控制器白色底槽 + 黑色胶囊；开关开了是柠檬绿；滑杆粗轨道、柠檬绿填充、白圆钮黑圈；抽屉 48rpx 圆角；导览卡大圆角、黑色「下一步」、圈的光是柠檬绿；纪念章庆祝卡是黑卡 + 柠檬绿标题和按钮

## 图标

`scripts/draw-icons.py` 写 `miniprogram/images/icons/*.svg`：24 × 24、2 宽圆头描边，自己画的（今日、营地帐篷、相机、体重秤、我的、火、饼图、时钟、日历、箭头、铃铛、闪光、餐具、书、刷新、几个人、铅笔、对勾、叶子、照片、靶心、奖杯）。`<image>` 不认 `currentColor`，颜色写进文件：深色一份，tab 用的另出 `-off`（灰），相机另出 `-white`；黑卡上的用 `filter: invert(1)` 反白。

## 首页

从上到下：问好 + 日期（右边白色圆钮去打卡日历）→ 新手三步（做完不显示）→ **下一顿黑卡**（时钟小圆章 + 「午饭时间到啦」+ 右边「还剩 40 分钟」柠檬绿胶囊；超大的 12:00；时间窗；暖豆小胶囊；柠檬绿「拍午饭」）→ **今天吃了**柠檬绿卡（大大的 34%、还能吃多少；右边粗圆环，中间白圆片写 420 / 1240）→ **三大营养素**（吃了 / 建议克数、百分比、粗进度条）→ **今天的暖豆**（大数字 + 三个大印章 + 连续天数）→ 今天的打卡（圆角照片、大字千卡、评级、箭头）→ 小暖的今日总结。

- 下一顿卡的版面字段在 `utils/view.js` 的 `nextMealHero`（kicker、big、pill、line、button），和 `nextMealCard` 用同一个 `mealStatus`
- 营养素的参照量在 `view.js` 的 `macroBars`：按每日预算的能量比例 碳水 50% / 蛋白质 20% / 脂肪 30%（《中国居民膳食指南》成年人范围内、减重偏多一点蛋白质），只是给进度条当参照
- 新手导览的顺序跟着版面：下一顿 → 今天吃了 → 暖豆 → 底栏「营地」→ 看说明

## 自定义底栏

`miniprogram/custom-tab-bar/`（`app.json` 的 `tabBar.custom: true`）：今日 · 营地 · **[拍照]** · 体重 · 我的。白底、上面两个大圆角；选中的 tab 图标下面一块柠檬绿胶囊；中间 108rpx 黑色圆钮去打卡页（打卡页按现在的时间自己选哪顿）。每个 tab 页有自己的一份底栏，按当前页面路径点亮，tab 页 `onShow` 里 `utils/tab-bar.js` 的 `syncTabBar(this)` 再对一次。营地原来底部的「拍一拍这一餐」去掉了（底栏就有）。导览指 tab 的那步按 5 格算（`tabs: 5`）。

## 其他页面

- 结果页：照片 40rpx 圆角；这顿多少千卡是柠檬绿卡（「约」+ 超大数字 + 千卡，营养素三块白底彩字）；吃了哪些 / 小暖说 / 重新分析都有卡片头；下一餐建议是一块浅灰圆角
- 打卡页：拍照是柠檬绿大卡、中间黑色大圆钮；准不准时是小胶囊（准时柠檬绿、不准暖橙）；几个人一起吃、想说的话各一张卡
- 日历：今天得了多少暖豆的橙色卡；月份两边圆钮；今天那格柠檬绿
- 体重：最近的变化是柠檬绿卡，大数字；曲线黑线
- 我的：每日建议吃多少是柠檬绿卡、大数字；三个入口是图标小圆章 + 箭头
- 提醒：三个饭点各一块浅绿圆角、大数字
- 营地：只换浮在画上的（暖豆余额白色胶囊、两边白色圆钮、提示条白色胶囊），画不动
