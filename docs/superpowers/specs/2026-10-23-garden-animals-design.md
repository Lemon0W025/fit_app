# 庭院小动物 — 设计文档

日期：2026-10-23 · 状态：待确认 · 修改：[养生庭院 + 扭蛋机](2026-10-23-garden-gacha-design.md) 中小动物的来源（原「不做：宠物」作废）

## 目标

让庭院「活」起来：小动物住进来以后自己走来走去，碰到喜欢的东西会吃、会玩、会打盹，点一下有反应。
摆设因此有了用处（摆翠竹是为了等熊猫），新动物又和每天打卡绑在一起，多一个盼头。

## 规则

### 谁喜欢什么

动物不再从扭蛋里出。庭院里摆了它喜欢的东西，它就会搬来：

| 小动物 | 喜欢（摆在庭院里才会来） |
|---|---|
| 小黄鸡 chick | 青草丛 grass |
| 小白兔 rabbit | 白萝卜 radish |
| 小花猫 tabby_cat | 小板凳 stool |
| 小乌龟 turtle | 鹅卵石 pebbles |
| 大熊猫 panda | 翠竹 bamboo |
| 小黄鸭 duck | 锦鲤池 koi_pond |
| 胖橘猫 ginger_cat | 茶桌 tea_table |
| 仙鹤 crane | 荷花池 lotus_pond |
| 熊猫一家 panda_family | 大熊猫已经住进来，且庭院里摆着 3 丛翠竹 |

「摆着」指在 `placed` 里（背包里的不算）。

### 什么时候搬来

- 只在正餐（早/午/晚）打卡成功写入后检查（`meal.analyze`）；AI 分析失败的打卡也算，和每天的树一致。加餐、重新分析、删除打卡都不触发。
- 每次打卡最多搬来一只。有几只在等时，按它喜欢的物件摆进庭院的先后（`uid` 序号小的先），熊猫一家按「第 3 丛翠竹」的序号排。
- 搬来后写进 `residents`，同时计入图鉴 `collected`，记入 `arrivals`（还没在庭院里看到的新住户）。
- 打卡结果页显示「🐼 大熊猫闻着竹子香，搬进庭院啦！」和「去庭院看看」；每只动物一句自己的搬家台词。
- 住进来就不走：喜欢的东西被移动或收回、打卡被删，都不影响。

### 庭院里的提示

- 有动物在等（条件满足但还没搬来）时，庭院页显示「有小动物在院子外张望…下次打卡它就来了」。
- 打开庭院时，`arrivals` 里的动物从院子边上走进来，头上冒「我是大熊猫，以后就住这儿啦！」。只有庭院页调用 `garden.get` 时带 `{ markSeen: true }`，返回后清空 `arrivals`；扭蛋页、图鉴页也会调 `garden.get`，但不带这个参数，不会把新住户「看掉」。

### 图鉴

- 新增「小动物」一组（9 只），排在稀有度分组之后、节气限定之前；没来的显示剪影和「喜欢：翠竹」（熊猫一家显示「喜欢：大熊猫 + 3 丛翠竹」）。
- 总数仍是 48，仍计入「集齐 20 种扩成 8×8」。
- 扭蛋池剩 39 件：普通 15 / 稀有 10 / 珍稀 6 / 传说 3 + 节气限定 5，稀有度概率、保底不变。

### 旧数据

`normalizeGarden` 把背包里、庭院里已有的动物物件转成住户（去重，`arrivals` 不放，免得一次走进来一群），并从 `inventory` / `placed` 里移除。目前只有试用数据会碰到。

## 庭院里的样子

### 走来走去

- 每只动物有一个「家」：它喜欢的物件所在的格子（摆了好几个取第一个；收回了就没有家，满院子逛）。
- 一步走到相邻（上下左右）的空格：没有物件、也没有别的动物；优先选离家 2 格以内的格子。走一步 1～2 秒，停 2～5 秒再走。
- 各有脾气：

| 动物 | 大小（格宽） | 走路 | 爱打盹 | 图朝向 |
|---|---|---|---|---|
| 小黄鸡 | 0.5 | 快，常蹦 | 很少 | 右 |
| 小黄鸭 | 0.5 | 中 | 很少 | 右 |
| 小乌龟 | 0.5 | 很慢 | 偶尔 | 右 |
| 小白兔 | 0.55 | 快，常蹦 | 偶尔 | 正面 |
| 小花猫 | 0.6 | 中 | 常常 | 正面 |
| 胖橘猫 | 0.7 | 很少动 | 大部分时间 | 左 |
| 大熊猫 | 0.8 | 慢 | 偶尔 | 正面 |
| 仙鹤 | 0.8 | 慢，优雅 | 不打盹 | 右 |
| 熊猫一家 | 1.1 | 慢 | 偶尔 | 正面 |

- 「图朝向」决定往哪边走时要镜像翻转；正面的图往左走时翻转，往右不翻。
- 动作效果（都用现有的单张图，靠 CSS 做）：走路时小幅弹跳；停下时轻轻「呼吸」（上下缩放）；打盹时冒「Zzz」。
- 和物件一起按前后排序，绕到树后面会被挡住，站在篱笆前面会挡住篱笆。

### 碰到物件的特殊动作

每走完一步，有 30% 机会找 3 格内能玩的物件，走到旁边（或上面）玩 5～8 秒，然后继续逛；同一件东西玩过后 1 分钟内不再找它。

| 物件 | 哪些动物 | 动作 | 位置 |
|---|---|---|---|
| 翠竹 | 大熊猫、熊猫一家 | 吃竹子：坐下、点头嚼，冒 🎋「嚼嚼」 | 旁边的空格，面朝竹子 |
| 白萝卜、大白菜 | 小白兔 | 啃：趴低、小口快嚼，冒 🥕 | 旁边 |
| 青草丛、晒枸杞红枣 | 小黄鸡 | 啄：快速点头，冒 🌾 | 旁边 |
| 锦鲤池、荷花池、九曲桥荷塘 | 小黄鸭、小乌龟、仙鹤 | 下水：下半身没入水里，水波一圈圈散开 💧；小黄鸭在池里绕半圈 | 物件上面（水面中心） |
| 小板凳、茶桌、石桌石凳 | 小花猫、胖橘猫 | 跳上去蜷着打盹 💤 | 物件上面（台面） |
| 秋千树 | 大熊猫、小花猫、胖橘猫 | 坐上秋千前后荡 | 物件上面（秋千座） |
| 鹅卵石 | 小乌龟 | 爬上去晒背 ☀️ | 物件上面 |
| 烤红薯炉 | 所有动物 | 围着烤火 ♨️ | 旁边 |

- 「旁边」要求物件相邻有空格；「上面」占用物件那一格，期间别的动物不能用同一件东西。
- 「上面」的落点按物件图片里的位置定（比如板凳台面在图高 55% 处），写在物件的互动数据里。

### 点一下

- 蹦一下，冒一颗 ❤️，头上气泡说一句话，3 秒后消失。
- 每只动物 4～5 句平常的话（可爱的 + 温和的养生提醒），正在做特殊动作时说对应的话（熊猫吃竹子时「别抢我竹子～」，猫打盹时「呼噜…再睡五分钟」）。
- 文案示例：小黄鸡「叽叽！早饭吃了没？」、大熊猫「竹子要慢慢嚼，吃饭也一样～」、胖橘猫「晒太阳好舒服，饭后也出来走走吧」、仙鹤「站直一点，腰背会舒服」。

### 摆放 / 移动物件时

动物原地停下、变半透明、不接收点击，不挡点格子；摆放时动物所在的格子仍算空地。物件放到动物脚下时，动物跳到最近的空格。退出摆放模式后恢复走动。

### 不做

喂食、饥饿、生病、离家出走、亲密度、给动物起名、拖动动物。

## 架构

### 云函数

| 位置 | 改动 |
|---|---|
| `lib/shared/garden.js` | 动物物件加 `kind: 'animal'`、`likes: [itemId]`、`likesCount`（熊猫一家 3）、`needs`（熊猫一家 `'panda'`）；`pickItem` 跳过动物；新增 `waitingAnimals(placed, residents)`（按搬来顺序排好的等候名单）、`ANIMALS`（动物 id 列表） |
| `lib/garden-state.js` | 默认 `residents: []`、`arrivals: []`；旧动物物件迁移成住户 |
| `services/garden.js` | 新增 `arrive(openid)`：取等候名单第一只写进 `residents` / `arrivals` / `collected`，返回 `{ id, name }` 或 `null`；`view()` 增加 `residents`、`arrivals`、`waiting`（id 列表）；`get({ markSeen: true })` 返回后清空 `arrivals`（不新增 action） |
| `services/meal.js` | 注入 `garden`；正餐 `analyze` 在 `forest.syncDay` 之后调 `garden.arrive`，响应里带 `arrival`（不存进打卡记录，同 `tree`） |
| `index.js` | 先建 garden service 再传给 meal service |

数据：`gardens` 文档新增 `residents: [{ id, since }]`（`since` 为日期）、`arrivals: [id]`。

### 小程序

| 位置 | 职责 |
|---|---|
| `utils/animals.js` | 纯数据 + 纯函数（注入随机数，可单测）：每只动物的大小、速度、爱打盹程度、图朝向、台词、搬家台词；物件互动表（动作、哪些动物、旁边/上面、落点、表情符号、台词）；`freeNeighbors`、`chooseStep`（偏向离家近）、`choosePlay`、`homeOf`、`lineFor(animal, action)` |
| `utils/garden-life.js` | 调度：`createLife({ size, placed, residents, arrivals, random, setTimer, clearTimer, onChange })`，每只动物一个定时器，算出下一步后回调 `onChange(index, sprite)`；`pause()` / `resume()` / `stop()` / `updatePlaced(placed)`（物件变动后让脚下有东西的动物让开）；`tap(index)` 返回气泡内容。定时器可注入，测试里手动推进 |
| `pages/garden` | 渲染 `animals` 列表（和物件同一层，`z-index` 按格子算）；用 `setData({ 'animals[i]': … })` 只更新一只；位移用 `transition`，各种动作是 CSS 动画类名（`walk`、`breathe`、`sleep`、`eat`、`peck`、`swim`、`swing`、`bask`、`warm`、`tap`）；`onHide` / `onUnload` 停定时器，进入摆放模式暂停；顶部「张望」提示 |
| `pages/meal` | 结果页显示 `arrival` 横幅 |
| `pages/checkin` | `globalData.lastTree` 带上 `arrival` |
| `pages/collection`、`utils/garden-view.js` | `collectionGroups` 加「小动物」组和「喜欢：…」提示 |

下水用外层 `overflow: hidden` 截掉下半身，再加一圈水波（CSS 椭圆边框动画）。镜像翻转放在内层，避免和弹跳动画的 `transform` 打架。

## 测试

- shared：`waitingAnimals` 的条件与排序（含熊猫一家、背包里不算、已住进来的不再等）、`pickItem` 不出动物、两份 shared 逐字节一致。
- garden service：`arrive` 一次一只、无等候返回 `null`、计入图鉴；`get({ markSeen: true })` 返回并清空 `arrivals`，不带参数时保留；`waiting` 正确；旧数据迁移。
- meal service：正餐打卡带 `arrival`、加餐 / 重新分析 / 删除不触发、AI 失败的正餐也触发。
- 端到端：摆翠竹 → 打卡午餐 → 返回 `arrival.id === 'panda'` → `garden.get({ markSeen: true })` 里有住户和 `arrivals`，再 get 一次 `arrivals` 为空。
- `utils/animals.js`：不走进物件 / 别的动物、偏向离家近、没有空格时原地不动、选互动物件（距离、冷却、别的动物占用）、落点、台词。
- `utils/garden-life.js`：推进定时器后位置变化、暂停后不动、`updatePlaced` 让开、`stop` 清掉所有定时器。
- 页面：庭院渲染出动物、点动物出气泡、离开页面定时器清零、摆放模式动物半透明；打卡结果页显示搬家横幅；图鉴有「小动物」组。

## 美术

不需要新图，动物用现有的 9 张。以后想更生动，可以让 Codex 给每只动物补「走路」「睡觉」姿势，`utils/animals.js` 里加姿势图字段即可替换。
