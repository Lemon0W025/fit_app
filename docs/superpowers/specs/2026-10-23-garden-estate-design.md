# 园林大宅院 — 设计文档

日期：2026-10-23 · 状态：待确认 · 取代：[小岛后花园](2026-10-23-island-garden-design.md)（12×12 方岛、四个角落、花坛、程序画的底图和篱笆遮罩）；修改：[庭院小动物](2026-10-23-garden-animals-design.md)（走动范围、作息、新动物）；保留小岛花园的首页布局（左上资源条、左右圆按钮、底部大打卡按钮）

## 目标

像模拟人生那样分开「房子的壳」和「家具」：

- **壳是画好的**：一座苏州园林式的大宅院，白墙黛瓦的墙和月亮门把它分成 11 个院子。墙、门、正房、铺地、池子、花坛的土、假山、瀑布都画在一整张原画里，院子里面是空的。
- **家具是你摆的**：扭蛋抽到的树、花、灯、桌、亭、荷花、锦鲤……摆进各个院子。什么东西摆什么地面有规矩，大件占 2×2 格、能左右转向、脚下有影子，摆出来像长在地里。
- **解锁 = 修好一个院子**：没修的院子盖着云雾，挨着已修好的院子才能修；修好后这个院子的壳露出来，里面靠你布置。
- **小动物住在整座宅院里**：穿过月亮门跑遍各院，一天有作息，会做可爱的小事；想找哪只，一键滑过去。树多了来小鸟，花多了来蝴蝶。
- 原画没到之前用程序搭的白模当底图，玩法全部先上。

## 宅院

### 坐标

- 等距格子：格宽 `tileW`、格高 `tileW / 2`。**1 倍缩放时一个院子（8 格 + 两边的墙）占满屏幕宽**：`tileW = windowWidth × 0.96 / 9`（375 宽的手机约 40px）。缩放 0.5～2 倍，第一次进来 1.2 倍、停在正院。
- 网格 37 (c) × 28 (r)。4 列院子（A～D）× 3 排（后、中、前），每个院子内部 8×8 格，院子之间隔 1 格墙；外圈也是 1 格墙。
  - 列：A `c 1～8`、B `c 10～17`、C `c 19～26`、D `c 28～35`；墙在 `c = 0, 9, 18, 27, 36`
  - 排：后 `r 1～8`、中 `r 10～17`、前 `r 19～26`；墙在 `r = 0, 9, 18, 27`
- 格子表由脚本按院子的形状生成到 `lib/shared/estate-map.js`（云函数和小程序共用）。每格两样属性：
  - `area`：属于哪个院子；墙、门、宅院外面是 `''`
  - `kind`：`lawn` 草地（能摆、能走）、`soil` 花坛/菜畦的土（只能种花种菜、能走）、`water` 水（只能放水里的东西、不能走；鸭子鹤乌龟能下水）、`pave` 石板铺地（只能放家具、能走）、`path` 小路（只能走）、`gate` 月亮门（只能走）、`wall` 墙、`block` 建筑/假山/池边（都不行）

### 修整

- 没修的院子盖着一团团云朵，慢慢飘。挨着已修院子的，在连通的月亮门里侧立木牌「修整荷塘院 · 200 暖豆」，点了弹窗确认；不挨着的只有云，没有木牌。
- 修好：云朵往四周飘散淡出、冒金色彩带，院子露出来；页面滑到这个院子中间。
- 文案：暖豆不够「暖豆不够啦，修整要 X 暖豆，再攒攒」；不挨着「要先修好旁边的院子」；已修好「这个院子已经修整好了」；不存在「没有这个院子」。

### 不能摆的原因（原文）

| 情况 | 提示 |
|---|---|
| 宅院外、墙上、建筑上 | 放不到这里哦 |
| 院子没修 | 这个院子还没修整呢 |
| 小路、月亮门 | 小路上不能摆东西 |
| 水里放了不是水里的东西 | 这是水里，放不了它 |
| 水里的东西放到岸上 | 它得放到水里 |
| 土里放了不是花草菜 | 土里只能种花种菜 |
| 铺地上放了植物 | 石板地上种不了，换块草地 |
| 大件有一格压到了别的东西或不合适的地面 | 这里放不下它 |
| 有东西 | 这块地上已经有东西了 |

### 新手礼与旧数据

- 第一次进花园：送 60 暖豆，大树种在正院 `(11, 16)`。
- 旧数据（文档里没有 `estate`）：已摆的东西全部收回背包；以前修整角落、开荒花掉的暖豆按当时的价格退回 `bonus`（小岛 `opened` 里 pond 200 / bamboo 300 / veg 400 / tea 500；大地图 `plots` 按 100、150、200…）；`opened` 重设为 `['front', 'main']`；大树重新种好。写回 `estate: 1`，以后不再迁移。

| 水生 | water | 荷花丛、睡莲、芦苇、锦鲤群、汀步石、小木桥（新） |

### 占格

- `foot: 2`（2×2 格）：六角凉亭、中式小茶楼、九曲桥荷塘、荷花池、锦鲤池、石拱桥、小水车、秋千树、葫芦架、花架。点的那一格是左前角 `(c, r)`，占 `(c, r)、(c−1, r)、(c, r−1)、(c−1, r−1)`，摆放模式亮 4 格；4 格都得是合适的地面、没东西。
- 其余 `foot: 1`。
- 图片宽度：1 格物件按 `size`（s 0.8 / m 1.0 / l 1.3 倍格宽）；2 格物件 2.2 倍格宽。

### 转向与影子

- 摆放、移动时底部多一个「↔ 换个方向」按钮，物件左右镜像；`placed` 多一个 `flip: true/false`。
- 所有物件、小动物脚下一个淡淡的椭圆影子（宽 = 图宽 × 0.7，高 = 宽 / 4，黑色 18% 透明）。

## 小动物

### 走动

- 能走的格子：已修院子里的 `lawn`、`soil`、`pave`、`path`、`gate`，没被物件和别的动物占着的；水鸟（鸭、鹤、龟）还能进 `water`。
- 一次走动的目标可以在别的院子，路径按格子寻路（广度优先）穿过月亮门；最多穿 2 道门，走太远就累。
- 新住户从大门 `(13, 27)` 走进来，一路走到你摆的它喜欢的东西旁边。

### 作息（按手机本地时间）

| 时段 | 去哪儿 |
|---|---|
| 6～9 点 | 往前院、正院凑，像等开饭：在院子里慢慢转、不睡 |
| 11～14 点 | 找阴凉打盹：猫上板凳、茶桌、长椅、水榭平台，熊猫靠着竹子或假山，其他在树下 |
| 其他白天 | 到处玩：去自己喜欢的东西那里（互动表照用），没事就逛，偶尔做小事 |
| 19 点后 | 回窝睡觉：小鸡 → 鸡舍（动物小院没修就在前院角落）；鸭、鹤、龟 → 荷塘或后花园的水；猫 → 正院屋檐下；熊猫一家 → 竹林院假山边；没修相应院子的在正院睡 |

时段只决定「偏好」：到点以后下一次选目标时按偏好选，不会瞬移。

### 小事

每只动物 2～3 件专属小事，白天随机触发（每只每 2～5 分钟一次），到位置后做 6～10 秒，头上冒表情和一句话。修好相关院子才会有：

| 动物 | 小事（院子） |
|---|---|
| 小花猫 | 井边照镜子（菜园）、追蝴蝶（花圃院）、晒肚皮（正院台阶） |
| 胖橘猫 | 泡温泉泡到打哈欠（温泉院）、趴茶桌边闻茶香（茶院）、追自己尾巴 |
| 大熊猫 | 抱着竹子打滚（竹林院）、泡温泉（温泉院）、倒挂在假山上 |
| 熊猫一家 | 排队过月亮门、小熊猫爬到大熊猫背上 |
| 小黄鸡 | 刨土找虫（菜园）、钻草垛（动物小院）、站在稻草人头上 |
| 小白兔 | 偷吃一口菜被「发现」（菜园）、钻草窝（动物小院）、后腿站起来张望 |
| 小黄鸭 | 排队过汀步石（荷塘院）、倒栽葱找鱼、瀑布下冲澡（后花园） |
| 小乌龟 | 翻过来蹬腿、缩进壳里、晒背（汀步石） |
| 仙鹤 | 单脚站着发呆（荷塘院）、展翅（后花园瀑布边）、梳羽毛 |

### 「找它」

右侧圆按钮里加「住户」：弹出列表，每行头像 + 名字 + 现在在哪在干嘛（「小花猫 · 在茶院打盹」「大熊猫 · 正往竹林院走」）；点一行关掉列表，地图滑过去把它放在屏幕中间，它头上冒一下爱心。

### 小鸟和蝴蝶（新动物，会飞）

| | 小鸟 `bird` | 蝴蝶 `butterfly` |
|---|---|---|
| 稀有度 | 稀有 | 普通 |
| 来的条件 | 院子里的树满 3 棵（桂花、橘子、柿子、梅花、银杏、秋千树、大树），**或**摆了喂鸟台 | 花满 3 丛（雏菊、小菊花、兰花、向日葵、蒲公英、腊梅、荷花丛、睡莲），**或**摆了花架 |
| 怎么动 | 在已修院子的树、假山、喂鸟台之间飞（直线飞、上下起伏），停下来 10～30 秒啾啾叫、歪头 | 在花、花架上方绕小圈飞，停一会儿再换一丛 |

| 点一下 | 飞起来绕一圈、一句话 | 飞起来绕一圈、一句话 |

新住户的来法和别的动物一样：条件满足后下次正餐打卡飞进来。`likes` 规则加一种：`likesAny`（任一件就够）。

## 画面

### 底图

- 原画：按白模用即梦画一整张（宅院 + 四周留一圈树木远山），切成 4 × 4 块放云存储 `garden/estate/`，页面按块铺。没到之前用白模切块当底图（放在包里，占位图压到 256 色）。
- 页面背景色取原画四周的颜色，拖出去不穿帮。
- 删掉程序画的小岛、篱笆遮罩、花坛和岛边花草、海浪。

### 云雾

- 每个没修的院子按它的格子范围铺 6～9 朵云，大小、位置固定随机，慢慢飘；先用程序画的云占位，即梦的云到了换上。
- 修好时云朵各自往外飘、淡出 0.8 秒，中间冒一下金色彩带。

### 摆在场景上的东西

- 物件、小动物用图 + 影子，按 `(c + r)` 前后排序；2×2 物件按它最前面那格排。
- 水里的物件和下水的动物只露上半身（现有的 `in-water` 做法）。

### 浏览

- `movable-view` 拖动缩放 0.5～2 倍；第一次进来 1.2 倍、停在正院；左下「🏠」回正院。
- 摆放模式只亮起当前选中物件能放的格子（按它的 `ground` 和 `foot`）。

## 测试

- 格子表：11 个院子都有能摆的格子；每道门两侧的格子能走；相邻关系双向；全部修好时任何能走的格子都能从前院走到；新手大树在正院草地上；每个院子的木牌位置在已修邻院能走到的门里侧
- shared：`placeProblem` 每种原因、2×2 占格、`canUnlock`、`walkable`（水鸟能进水）、`likesAny`
- service：修整（扣豆、不挨着、已修、豆不够、不存在）、`flip`、旧数据迁移（小岛、大地图、小庭院三种）
- 端到端：修好荷塘院 → 放荷花丛 → 打卡 → 仙鹤搬来；树 3 棵 → 小鸟
- `world.js`：布局、底图切块、云朵和木牌只在该出现的地方、点按换算、2×2 的亮格
- `garden-life`：穿过月亮门到别的院子、不进没修的院子、到点回窝、小事触发、`whereIs`、飞行动物白天出现晚上消失
- 页面：首页流程、各种不能摆的提示、换方向、修整（不挨着时没有木牌）、住户列表滑过去

## 上线节奏

1. **宅院本身**：格子表、11 个院子、地面规矩、2×2 和转向、影子、修整、小动物跨院与作息、小事、「找它」、迁移。白模当底图。
2. **原画**：用户按出图说明在即梦画好 → `cut_art.py` 切块 → `wx:art` 上传 → 页面切到云存储的图。
3. **新物件和小鸟蝴蝶**：先用 emoji 占位图上线，正式图到了 `slice-art.py` 切换。

## 不做（YAGNI）

物件旋转 90°、物件大小自由缩放、小动物进屋、点建筑进去有功能、昼夜光照和天气、多座宅院、好友串门。
