# 小岛后花园 — 设计文档

日期：2026-10-23 · 状态：待确认 · 取代：[大地图庭院](2026-10-23-big-garden-map-design.md) 中的 3×3 地块与开荒；保留其中的「去掉每日的树」（印章 + 暖豆）

## 目标

参照用户发来的游戏截图：一座精致、满满当当的小岛后花园，打开小程序就是它。

- 不再有大片空地和杂草荒地：小岛边上、路边、角落铺满花草；能摆东西的地方之外，到处都有景色。
- 小岛四个角落用篱笆围着，花暖豆「修整」，修好后角落里自带的风景一下子出现。
- 小动物和花草联动、只有一个扭蛋机（不变）。
- 花园做首页，底部一个大大的「拍一拍这一餐」。

## 小岛

### 形状与分区

小岛是 12×12 格的等距菱形（格子平时不显示，只在摆放时亮出能放的空地），分成：

| 分区 | 格子范围（c, r 都是左闭右开） | 说明 |
|---|---|---|
| 中间花园 `center` | c 3～9，r 3～9 | 一开始就有 |
| 荷塘角 `pond` | c 3～9，r 0～3 | 修整价 200 |
| 竹林角 `bamboo` | c 0～3，r 3～9 | 修整价 300 |
| 菜园角 `veg` | c 9～12，r 3～9 | 修整价 400 |
| 茶亭角 `tea` | c 3～9，r 9～12 | 修整价 500 |
| 四个花坛 | 剩下四个 3×3 的角（c、r 都 < 3 或都 ≥ 9，以及一个 < 3 一个 ≥ 9） | 永远是满满的花草树木，不能摆东西，小动物也不进去 |

- 小路：c = 6 那一列和 r = 6 那一行（在已修整的分区里），十字穿过小岛。小路上不能摆东西，小动物可以在上面走。
- 小岛外面是海：页面背景是浅蓝渐变加几道浪花，小岛下面露出沙滩和悬崖土边。原来岛外的枯树、石头去掉（外面是海）。

### 修整角落

- 四个角落都挨着中间，先修哪个都行；价格固定（200 / 300 / 400 / 500），共 1400。
- 没修的角落：盖着「篱笆 + 杂草」，角落中间立木牌「修整荷塘角 · 200 暖豆」，点木牌弹出「花 200 暖豆修整荷塘角？」。
- 修好：篱笆和杂草淡出、冒一团尘土，角落里自带的风景出现，空着的草地可以摆东西。
- 提示文案：暖豆不够「暖豆不够啦，修整要 X 暖豆，再攒攒」；已修好「这个角落已经修整好了」；不存在「没有这个角落」。

### 自带风景

每个分区有固定的风景（不能移动、不占背包、不算图鉴），每件占一格，挡住摆放也挡住小动物：

| 分区 | 风景（临时用现有物件图） |
|---|---|
| 荷塘角 | 荷花池 × 1（放大）、锦鲤池 × 1 |
| 竹林角 | 翠竹 × 2、灯笼柱 × 1（只放 2 丛：熊猫一家要 3 丛，得自己再摆一丛） |
| 菜园角 | 大白菜 × 1、白萝卜 × 1、南瓜 × 1、木篱笆 × 1 |
| 茶亭角 | 六角凉亭 × 1（放大）、石桌石凳 × 1 |

- 修好的角落里，风景也算小动物「喜欢的东西」：修好竹林角，下次正餐打卡熊猫就会来；荷塘角引来仙鹤和小黄鸭；菜园角引来小白兔。
- 小动物也会去风景那里玩（荷塘里游、竹子旁吃竹子、石桌上打盹……），规则同现在的互动表。

### 铺满花草

- 四个花坛：每个铺 6～8 棵/丛花草树木（用现有物件图：雏菊、小菊花、向日葵、蒲公英、青草丛、蘑菇、桂花树、橘子树……），按前后排好。
- 小岛外沿一圈：每隔一段放一丛小花草或小石头，压在岛边上，让岛的边缘不再是一条直线。
- 这些只是景色：不能点、不挡小动物（它们不在格子上）。

### 新手礼

第一次进花园：送 60 暖豆，并在中间花园 (4, 4) 种一棵大树（小路交叉口的后方）。

## 首页与界面

### 底部标签

「花园 · 今日 · 体重 · 我的」：花园排第一，打开小程序就是花园。第一次使用、还没建档时，花园页跳到「我的」去建档（原来由今日页做的事）。

### 花园页（全屏、自定义导航）

- 左上：深蓝色游戏风资源条（暖豆图标 + 数量），下面一行「今天得了 X 暖豆」+ 早午晚三个小印章（没打卡时「今天还没打卡」）。
- 右上：微信胶囊按钮下面「图鉴 x/48」。
- 顶部小横幅：节气限定、「有小动物在院子外张望」（有就显示）。
- 左侧一列圆按钮：图鉴、打卡日历。
- 右侧一列圆按钮：扭蛋机（暖豆 ≥ 30 时右上角小红点）、背包（角标件数）。
- 底部正中：大号绿色按钮「📷 拍一拍这一餐」，进打卡页。
- 左下角：小「🏠」回到小岛中间。
- 拖动、缩放（0.5～1.5 倍）、背包抽屉、摆放模式、点物件移动/收回、小动物，都沿用现在的做法。

### 打卡结果页

底部「回到今日」改成「回到花园」（回花园 tab）。

### 文案

界面上的「庭院」统一改叫「花园」（标签、欢迎弹窗、提示语、图鉴说明等）。

## 美术

- 现在：程序画小岛底图（一整张：草地、十字石板路、花坛底色、沙滩边、悬崖土边），篱笆杂草遮罩、木牌、尘土沿用/新画；风景、花坛、岛边花草都用现有正式物件图。
- 以后：程序另出一张「小岛布局草图」（`art/guide/island-layout.png`：分区、小路、花坛、风景位置都画出来），用户交给 Codex 参照草图画整张精致底图和各角落的风景、篱笆遮罩；大图放云存储（miniprogram-ci 的 `cloud.uploadStorage`），正式图到了再加上传命令和切换。

## 架构

### 云函数

| 位置 | 改动 |
|---|---|
| `lib/shared/garden.js` | 去掉 3×3 地块（`PLOT_*`、`plotOf`、`canExpand`、`expandCost` 等）；新增 `ISLAND_SIZE = 12`、`REGIONS`（id、名字、价格、范围）、`regionOf(c, r)`、`isPath(c, r)`、`SCENERY`（uid、分区、物件 id、c、r、scale）、`sceneryIn(opened)`、`tileOpen(opened, c, r)`（在已修整分区里）、`tilePlaceable(opened, c, r)`（开着、不是小路、没有风景）；`waitingAnimals` 不变，调用方把已修整分区的风景并进去 |
| `lib/garden-state.js` | 新字段 `opened`（已修整的分区 id）默认 `['center']`；旧数据迁移：有 `plots`（大地图）的，中间那块的物件坐标各减 3，落到小路上或别的块里的物件收回背包，开荒花掉的暖豆加回 `bonus`；更早的小庭院坐标各加 3 |
| `services/garden.js` | `view` 去掉 `plots`、`expandCost`、`world`，加 `regions: [{ id, name, cost, unlocked }]`；`checkTile` 用 `tilePlaceable`（不在岛上「放不到花园外面哦」、没修整「这块地还没修整呢」、小路「小路上不能摆东西」、风景「这里已经有风景了」）；`expand` 换成 `unlock(openid, { region })`；`arrive` 把已修整分区的风景算进喜欢的东西；新手大树放 (4, 4) |
| `router.js` | `garden.expand` 换成 `garden.unlock` |

## 测试

- shared：分区、小路、风景、`tilePlaceable`、`sceneryIn`。
- garden service：修整（扣豆、各种失败）、摆放 / 移动的各种拒绝、风景引来小动物、旧数据迁移（大地图、小庭院两种）、新手大树位置。
- 端到端：修整竹林角 → 正餐打卡 → 熊猫搬来。
- `world.js`：布局尺寸、遮罩和木牌、风景、花坛、点按换算。
- `garden-life`：不进花坛和没修整的角落、会去风景那里玩。
- 页面：花园做首页（没建档跳去建档）、左上今日暖豆和印章、大按钮去打卡、修整确认、结果页回到花园；其余沿用。
