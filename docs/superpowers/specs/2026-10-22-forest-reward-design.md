# 养生森林（打卡奖励机制）— 设计文档

日期：2026-10-22 · 状态：已确认 · 前置：[养生师打卡小程序设计](2026-10-22-yangsheng-coach-design.md)

## 目标

让长辈每天有成就感、愿意坚持打卡。参考 Forest：每天种一棵树，坚持的日子长成一片森林。

成功标准：

- 每次打卡后立刻看到"今天的树"的变化，以及下一步怎么让它长得更好。
- 一个月后打开森林页，坚持的日子连成一片，一眼看出哪天断了。
- 规则一句话能讲清，不扣分、不惩罚。

## 已确认的决策

| 项 | 决定 |
|---|---|
| 核心玩法 | 每天一棵树（Forest 式），按月排成森林 |
| 成长依据 | 打卡 + 吃得好；不扣分；体重不参与 |
| 长期奖励 | 累计种树数解锁新树种（只收集，不绑真实奖励） |
| 断签 | 没打卡的日子是空地，不出现枯树；连续天数归零 |

## 规则

### 当天的树

只看三顿正餐（早餐、午餐、晚餐），每种餐次取当天最新的一条打卡：

| 正餐打卡情况 | 树 |
|---|---|
| 0 顿 | 空地 `empty` |
| 1 顿 | 树苗 `sprout` |
| 2 顿 | 小树 `small` |
| 3 顿，绿色评级 ≤ 1 | 大树 `big` |
| 3 顿，绿色评级 = 2 | 开花 `bloom` |
| 3 顿，全部绿色 | 结果 `fruit` |

- 分析失败的打卡也算"打卡了"（打卡这个习惯本身被奖励），只是没有评级。
- 加餐照常打卡、照常点评，但不影响树：不会因为吃了不健康的零食受罚，也不会为了树去多吃。
- 删除打卡或重新分析后，树自动重算。

### 提示语（下一步怎么做）

| 当前 | 提示 |
|---|---|
| 空地 | 打卡一顿正餐，种下今天的树 |
| 树苗 | 再打卡{下一个没打的正餐}就能长成小树 |
| 小树 | 再打卡{没打的正餐}就能长成大树 |
| 大树 | 三顿都打卡啦！明天多吃几顿绿色的，就能开花 |
| 开花 | 真棒！明天三顿都吃成绿色，就能结果 |
| 结果 | 今天的树结果啦，完美的一天！ |

### 连续天数

当天有树（≥ 1 顿正餐）即算一天。今天还没打卡时，连续天数算到昨天为止（今天还有机会续上）。

### 树种与解锁

按累计有树的天数解锁，解锁后永久保留：

| 树种 | id | 解锁条件 |
|---|---|---|
| 苹果树 | apple | 起始 |
| 橘子树 | orange | 累计 7 棵 |
| 桃树 | peach | 15 棵 |
| 石榴树 | pomegranate | 30 棵 |
| 柿子树 | persimmon | 50 棵 |
| 樱桃树 | cherry | 80 棵 |

- 用户在森林页选择"当前树种"；今天的树随之改变，过去的日子不变。
- 某天第一次打卡正餐时，这一天记为当时的树种。
- 新解锁时，下一次打开今日页弹出庆祝提示（只弹一次）。

## 架构

### 数据

新集合 `gardens`，`_id = openid`：

```
{ _openid, currentSpecies, days: { 'YYYY-MM-DD': speciesId }, unlocked: [speciesId], unseen: [speciesId] }
```

- `days` 记录每天种的树种，同时是累计种树数与连续天数的来源。
- 删除打卡后该日已没有正餐时，从 `days` 删除这一天。
- 树的阶段不存库，始终由当天打卡记录实时计算。

### 代码

| 位置 | 职责 |
|---|---|
| `lib/shared/forest.js`（前后端共用） | 树种表、阶段名、`dayTree(meals)`、`treeHint(tree)`、`streakFrom(days, today)`、`unlockedFor(total)`、`nextUnlock(total)` |
| `services/forest.js` | `recordDay`、`pruneDay`、`today`（今日树 + 连续天数 + 新解锁，读后标记已看）、`get`（月视图）、`setSpecies` |
| `services/meal.js` | 新增正餐打卡时 `recordDay`；删除后 `pruneDay`；`analyze`/`reanalyze` 的返回值附带 `tree: { before, after, hint, species }` |
| `services/day.js` | `day.get` 附带今日树卡片数据 `tree` |
| `repo.js` | `getGarden`、`saveGarden`、`listMealsBetween(openid, start, end)` |

新 actions：`forest.get { month? }`、`forest.setSpecies { species }`。

### 页面

- **新标签页「森林」**（今日、森林、体重、我的）：顶部今天的大树、阶段、提示、🔥 连续天数；树种选择（未解锁显示还差几棵）；按月日历森林（可切换月份），点某天显示当天几顿、多少千卡；本月种树数、结果数。
- **今日页**：顶部今日树卡片，点击进入森林；有新解锁时弹庆祝提示。
- **餐详情页**：打卡后显示"今天的树长成小树了 🌿 / 再打卡晚餐就能长成大树"。

### 美术

Forest 风格：等距小草地块上一棵树。树苗、小树通用；大树、开花、结果按 6 个树种各一张（花色、果色不同）；外加空地块。共 21 张 PNG，PIL 程序化绘制。另加「森林」标签图标。

## 测试

## 不做（YAGNI）

补签卡、勋章墙、真实奖励兑换、排行榜、体重参与成长。
