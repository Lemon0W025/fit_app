# 营地：今日菜单、正面 / 背影走路 — 设计文档

日期：2026-10-26 · 状态：用户选了「A 今日菜单」和「正面也一起画」

## 背景

1. 现在一样食物基本只对应一只小动物（胡萝卜只引糯糯），还得同稀有度；那只住下了，这样食物就再也引不来谁。用户想要「指定的食物当天能吸引来某几种小动物」，每天不一样。
2. 小动物往上走（背对着我们）时还是侧身的走路动画，像在原地跳。要按走的方向换画面：往上走看背影、往下走看正面、左右走照旧侧面。

## 一、今日菜单

### 规则（云函数 `lib/menu.js`，纯函数）

- `dailyMenu(date)` → `{ <foodId>: [petId, …] }`，只算 23 样普通食物（节气点心照旧不引客人）。同一天每次算都一样，第二天换一批（按 `date:foodId` 做种子的伪随机）。
- 每样食物的名单：
  - **本来就爱吃它、同稀有度的**那只（或几只）一直在名单里（就是现在 `arrivalFor` 的候选，莲子是莲莲、山楂是鹤鹤）；
  - 再加 0～2 只「今天闻得到它」的：从**同稀有度**（权重 3）和**低一档**（权重 1）的小动物里挑，不重复。普通食物只会加普通的，越稀有的食物名单里越偏稀有（山楂会加珍稀的）；
  - 一共最多 3 只；加几只：0 只 20%、1 只 45%、2 只 35%。
- 下锅时挑客人：从这样食物今天的名单里，挑一只还没住下、也不是客人的（随机）；名单里都来过了就没有客人。住户来吃照旧按「本来爱吃」（`feedGain`）。
- `camp.get` 等返回的 view 多一个 `menu`（今天的整张菜单）。

### 页面

- 背包「吃的」每一格下面一排小头像：今天闻着它会来的。住下的和客人显示头像，还没来过的显示**剪影**（同一张头像图压黑、半透明）。
- 拿起一样食物时，底部提示条里也放这排头像：「今天闻着它会来」。
- 点锅、提示条、客人的话都不变。

## 二、正面 / 背影走路

### 美术（第 3 批，给 Codex）

每只多一张 **C 张**拼图 `art/raw/anim/<id>-c.png`（和 A、B 一样 1:1、6 列 × 6 行、透明底），6 行：

| 行 | 内容 |
|---|---|
| 1 | 背影走路（往远处走，看到后脑勺、背和尾巴）|
| 2 | 正面走路（朝镜头走过来，看到脸）|
| 3 | 背对着站（待机：呼吸、耳朵 / 尾巴动）|
| 4 | 背对着吃（在锅边低头吃）|
| 5 | 背对着坐（围着篝火坐）|
| 6 | 正面站着看你（待机：呼吸、眨眼）|

鹤鹤第 1、2 行是飞（背影 / 正面）。工单写进 `docs/art/camp-art-pack.md` 第 3.5 节和「执行流程」的第 3 批开场指令，`art/manifest.json` 加 12 张。

### 代码

- `anim.js`：`SHEET_ROWS.c`；`frameFor(action, { sleepStyle, dir, c })`：有 C 张时，`dir === 'back'` 的 走 / 飞 / 待机 / 吃 / 坐 换成背影那几行，`dir === 'front'` 的 走 / 飞 / 待机 换成正面；别的动作、或者没有 C 张，照旧用 A / B 张（侧面）。
- `camp-life.js`：每只记 `dir`（side / back / front）。走每一小段时按方向定：竖着的位移比横着的大 1.2 倍以上就是 back（往上）/ front（往下），否则 side；停下来待机保持最后走的方向；在锅边吃、围火坐、客人在锅边闻时，站在锅前面（比篝火靠下）的面朝锅 = back；做别的动作（蹭你、打滚、被摸、睡觉……）回到 side。
- `anim-sheets.js`：打包时有 C 张的记 `c: true`（`pack_anim.py` 认 `<id>-c.png`，可选）。**一只一张**：A、B、C 上下拼成 6 × 18 格（`anim.stackRow`），换动作、转身只挪行、不换图——一开始是三张分开、转身换 src，真机上转身会闪一下，10/26 改成拼一张。
- 没画 C 张之前一切照旧。

### 10/26 补：橘团、茶茶重画走路

用户看出橘团走路「像瘸了一样翘着脚」、茶茶「只有前脚在走」：是第 2 批 A 张第 1 行画坏了（橘团 6 帧几乎一样、一只后脚一直翘在后面；茶茶后腿 6 帧里 5 帧不动、第 4 帧突然一大步），对齐和播放没问题。
只重画这一行：工单第 3.6 节 + 第 4 批开场指令，单独一张 `art/raw/anim/<id>-walk.png`（3:2，3 × 2 = 6 帧，格子大、腿画得清楚，6 帧逐帧写清楚对角两两交替），
`pack_anim.py` 看到它就换掉 A 张第 1 行（个头按原来那行缩放），其他行不动。manifest 加 2 张。10/27 第 4 批接入（`camp/anim-v6/`）。

## 三、测试

- `menu`：同一天一样、换一天不同；本来爱吃的一直在；最多 3 只、不重复；普通食物只有普通的；山楂只有鹤鹤和珍稀的；点心没有名单。
- 服务：下锅从今天的名单里挑客人（不挑已经住下 / 已经是客人的），名单都来过了没有客人；view 带 `menu`。
- `camp-view.foodBag`：头像、剪影。
- `anim.frameFor`：有 C 张时 back / front 换行，没有照旧。
- `camp-life`：往上走 back、往下走 front、横着 side；锅前面吃是 back；蹭你回到 side；精灵的 anim 用 C 张（`sheets` 里有 `c`）。
- 页面：背包头像；有 C 张的宠物下三张。

## 实现顺序

1. 云函数 `lib/menu.js` + `putFood` 用菜单 + view 带 `menu` + 测试，部署

3. `anim.js` C 张 + `camp-life` 朝向 + 页面下 C 张 + `pack_anim.py` + 测试
4. 工单第 3 批、manifest、文档；测试、推送、部署、预览
