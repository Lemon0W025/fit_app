# 营地：食物下锅、夜里的光、随机小睡、不瞬移、放大 — 设计文档

日期：2026-10-25 · 状态：已确认（用户逐段确认过）

## 背景与目标

用户试了营地之后的反馈：

1. 不知道怎么把锅点亮（现在是「今天拍了正餐，火才点着」，营地里看不出来）。希望**放食物进锅就点火煮饭**，香味引来爱吃它的小动物，食物越稀有引来的越稀有；不要食盆了。
2. 夜里灯边的小动物也是灰的，灯好像没亮；篝火点着的时候应该全营地都亮。
3. 天一黑全体睡觉太统一；希望随机小睡（十几秒到几分钟），有的睡有的玩，点它就醒。
4. 每次切回营地，小动物都瞬移回同一个起点。
5. 小动物有点小。

打卡仍然是第一位：营地里打卡管一头一尾——开头给暖豆（抽食物），结尾让闻香而来的客人住下。

成功标准：

- 妈妈一看就懂：抽到的食物放进锅里，火就着、锅里冒热气，爱吃的小动物跑过来。
- 新小动物只在拍正餐打卡后住下，打卡依旧是「钥匙」。
- 夜里火着着时，小动物和装饰都是本来的颜色；火没着时灯边是暖亮的。
- 任何时候都不会全体同时睡觉；点睡着的会醒。
- 切回营地、重开小程序，小动物还在原来的地方。

## 已确认的决策

| 项 | 决定 |
|---|---|
| 锅 | 去掉两个食盆；食物直接下锅，一天最多 3 样不同的，下了不能拿出；第一样下锅就点火，煮一整天，半夜清空熄火 |
| 打卡和锅 | 打卡不再点火、不再加锅里的层数 |
| 引来谁 | 爱吃这样东西、和它一样稀有、还没来过的小动物（现有 `arrivalFor` 规则）；下锅那一刻就从营地边上跑来当「客人」 |
| 客人住下 | 下一次拍正餐打卡，所有客人一起住下；客人不会自己走，锅清空了也等着 |
| 住户 | 爱吃锅里东西的住户走到锅边吃，亲密度 + `feedGain`（爱吃 3、节气点心 5） |
| 夜里的光 | 火着着：全营地本来的颜色（略暗略暖）；火没着：月光色，但画上的提灯、帐篷门口和摆的小灯笼 / 石灯笼 / 灯串周围一圈是暖亮的 |
| 睡觉 | 随机小睡：白天 10～40 秒、同时最多 1/4；夜里 1～5 分钟、同时最多 1/2；点睡着的就醒 |
| 不瞬移 | 离开营地时记下每只的位置、朝向、动作，回来从原地接着来（存手机里，重开也在） |
| 大小 | 小动物整体放大 1.3 倍（录屏看过再微调，1.2～1.5） |

## 一、锅、食物、客人

### 一圈怎么转

打卡挣暖豆 → 暖豆抽扭蛋得食物 → 食物下锅（点火、煮一天）→ 香味引来小动物（住户来吃、新的来当客人）→ 下一次拍正餐，客人住下 → 住户每次打卡都算喂一顿。

### 锅

- 营地数据 `pot: { date, foods: [] }`，`date` 是下锅那天（北京时间）。读的时候 `date` 不是今天就当空锅（半夜清空，不用定时任务）。
- `camp.putFood { foodId }`：从背包拿一样放进今天的锅。
  - 锅里已经有 3 样：`BAD_REQUEST`「锅里已经煮了三样啦，明天再放」
  - 同一样今天已经下过：`BAD_REQUEST`「锅里已经有{名字}了，换一样吧」
  - 背包没有：沿用「背包里没有这个了」
- 下锅那一刻：
  - **住户**：爱吃它的（`pet.foods` 含它，或者是节气点心）亲密度 + `feedGain(petId, foodId)`，记在返回的 `eaters` 里（页面让它们走到锅边吃）。
  - **客人**：`arrivalFor(foodId, 住户 + 已有客人, random)` 选一只（节气点心不引客人）；有就加进 `visitors: [{ id, foodId, since }]`，返回的 `visitor` 是它。
- `camp.takeFood` 删掉（下了锅不能拿出来）。
- 页面上：锅的层数 = 今天锅里几样（0～3），沿用现有的 `pot-0～3` 抠图、火苗逐帧、热气（两样起一缕、三样两缕）；锅里没东西就是熄火的样子。

### 客人

- 客人在营地里看得见：从营地边上（`SCENE.entries`）跑进来，到锅边附近转悠、闻一闻，头上「好香啊……」。
- 不显示名字、不能喂、不在「找它」里；点它说「它闻着{食物}的香味来的。妈妈下次拍正餐，它就住下来」。
- 顶上的提示条：「👀 糯糯闻着香味来了…下次拍正餐就住下」（取代现在「在树林边张望」那句）。
- 鹤鹤只在 5～9 点出现：当了客人也按它的钟点出现。

### 打卡（正餐）时

- `camp.arrive`：全员 +1 亲密（不变，一天最多 3 次）；**所有客人住下**（加进 `pets`、`arrivals`，清空 `visitors`）。
- 返回 `{ pets: [{ id, name, foodName }] }`，没人住下返回 `null`。
- 结果页横幅：一只「糯糯闻着胡萝卜的香味，住进营地啦！」；几只「糯糯、笋宝住进营地啦！」（图用第一只）。
- 原来「没人可引的食物由爱吃的住户吃掉」那段删掉（住户在下锅时就吃了）。

### 旧数据

`normalizeCamp`（`camp: 2`）：食盆里的食物退回背包；正在张望的（还没住下的）变成客人；删掉 `bowls`、`peeking`。`camp` 从 1 升到 2，旧档读到就存一次。

### 页面

- 拖食物：从背包拖到**锅上**松手就下锅（命中锅的抠图框）；拖到住户身上仍然是直接喂。提示改成「拖到锅里或者小动物身上松手」。
- 点锅：锅空着就打开背包的「吃的」；锅里有东西弹一句「锅里煮着：胡萝卜、小米。爱吃的小动物会过来」。
- 去掉食盆的一切：碗里的食物图（`images/camp/foods/bowl/`，删掉省包）、碗沿抠图、`tapBowl`、`bowlViews`。画上的两个碗留着当摆设，仍然是走路要绕的东西。（10/26 用户说碗用不到就去掉：`scripts/camp/erase_bowls.py` 把碗和影子从日景 / 夜景原图、Codex 的两张「没点火」上擦掉补成草地，`SCENE.bowls` / `bowl` 和碗的遮挡删了。）
- 扭蛋页、图册里「放进食盆」之类的字改成「放进锅里」。

## 二、夜里的光（`utils/camp-light.js`）

- `nightLook(x, y, lit, lamps)`：
  - `lit`（今天锅里有东西）：所有位置一样，`brightness(0.92) saturate(1) sepia(0.12)`，月光层 0。
  - 没点火：沿用 `_OFF` 那套（远处月光色），再按灯的远近提亮：每盏灯 `{ x, y, r }`，`f = max over lamps of (1 - (d / r)²)⁺`；`f` 越大越接近暖亮（亮度往 0.9 拉、偏暖、月光层乘 `1 - f`）。连续变化，走过去不跳色。
- 灯：画上的提灯（`SCENE.cutouts.lantern` 的中心）r 480、帐篷门口 r 520，加上摆着的 `fx: 'glow'` 装饰（小灯笼、石灯笼 r 420，灯串 r 560）。
- 宠物、装饰都用它；白天不变。

## 三、随机小睡（`utils/camp-life.js`）

- 去掉「夜里全体去睡」。每次轮到一只决定做什么时，先掷一次「困了」：
  - 白天概率 6%、夜里（19～6 点）35%；
  - 正在睡的已经到上限就不睡：白天同时最多 1/4（至少 1 只）、夜里最多 1/2；
  - 睡多久：白天 10～40 秒，夜里 1～5 分钟；
  - 睡哪：离它最近的空着的睡觉点（帐篷门口、树荫、草窝 / 吊床这类装饰），走过去最多 600 画像素；没有就原地趴下。
- 点睡着的：马上醒，做「开心」那行动作 + 说「嗯…？醒啦」，然后接着活动。
- 傍晚（17～19 点）围火坐：只在火着着时；火没着各玩各的。
- 客人不睡。
- 锅里有它爱吃的：白天偶尔（15%）走到锅边吃一会儿。

## 四、不瞬移

- `life.snapshot()` → `{ <id>: { x, y, right, action, until, sleepStyle } }`（`until` 是睡到几点，毫秒时间戳；别的动作不记时间）。
- 页面 `stopLife` 时把快照存进 `globalData.campSpots` 和本地存储 `campSpots`（`wx.setStorageSync`，失败忽略）；`createLife({ saved })` 用它摆初始位置：
  - 有快照、位置不在禁区和装饰落脚框里：站在原地、朝向不变；`action === 'sleep'` 且 `until` 还没到就接着睡到 `until`，否则从 `idle` 接着来。
  - 没快照或位置不行：按现在的 `settle`。
  - 走到一半离开的：快照里记的是它正要走到的那一段的终点（`a.x / a.y` 本来就是），回来就站在那儿。
- 新住户（`arrivals`）和客人：从营地边上走进来。

## 五、放大

- `camp-life` 的宠物宽度乘 `PET_ZOOM = 1.3`（影子、点击框、气泡位置跟着）；`shared/pets.js` 的 `size` 不动（不用重新部署共用文件）。
- 录屏对比后再定，1.2～1.5 之间调。

## 六、怎么搭

- 云函数：`lib/camp-state.js`（`camp: 2`、`pot`、`visitors`、旧档迁移）、`services/camp.js`（`putFood` 改、`takeFood` 删、`arrive` 改、`view` 带 `pot`、`visitors`）、`router`（去掉 `camp.takeFood`）。共用文件不改。
- 小程序：`utils/camp-view.js`（`potView`、`arrivalCard` 认多只、删 `bowlViews` / `potLevel(daily)`）、`utils/camp-light.js`（`nightLook` 加灯）、`utils/camp-life.js`（客人、来吃的住户、随机小睡、点醒、快照、放大）、`utils/scene-fx.js`（不变，`potLevel` 换来源）、`pages/camp`（锅的拖放和点按、提示条、存取快照）、`pages/meal` 横幅、扭蛋 / 图册的字。
- 删：`images/camp/foods/bowl/`、`scripts/camp/bowl_food.py`、碗沿抠图的使用。

## 七、测试

- 服务：下锅（点火、3 样上限、同样不能下两次、背包扣一个、住户爱吃 +3 / 点心 +5、客人选对稀有度、不重复挑已是客人的、点心不引客人）、过了半夜锅是空的、`arrive` 让所有客人住下并返回名单、旧档迁移（碗里的退回背包、张望的变客人、`camp: 2`）。
- 端到端：扭蛋 → 下锅 → 客人 → 打卡 → 住下 → 图册。
- `camp-light`：点火时全营地月光层 0；没点火时灯边月光层小于远处、越近越亮。
- `camp-life`（假时钟 + 固定随机数）：任何时刻睡着的不超过上限；夜里不是全体睡；点睡着的会醒；快照 → 新建 → 位置一样、没睡完接着睡；客人从入口进来；`eaters` 走到锅边；宽度是原来的 1.3 倍。
- 页面：拖到锅上调 `camp.putFood`；点锅；提示条；离开再回来位置不变。
- 录屏：`record-camp.js` 加「下锅」「夜里点火 / 灯边」「随机小睡」场景，逐帧看。

## 不做（YAGNI）

- 煮饭的倒计时、多锅、锅升级。
- 客人等太久自己走掉。
- 灯串、灯笼的光照亮画本身（只照小动物和装饰）。
- 小动物的体型按物种单独调。
