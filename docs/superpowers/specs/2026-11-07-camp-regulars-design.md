# 营地：常客与住下（2026-11-07）

用户反馈（11/07 晚）：① 小动物在锅边待的时间太久、动作单一，不去周围走走、不和家具玩；② 希望改成：小鸡（豆豆）一直在；别的小动物锅里有吃的就来、吃的没了就走，一样吃的管一顿（24 ÷ 3 = 8 小时），下一顿没放就走；喂到亲密度满了就「住下」，之后不走。取代 `2026-10-25-camp-pot-design.md` 里「客人下次拍正餐就住下」和「不够亲的出去找吃的」那两条。

## 规则

1. **豆豆永远在**（新手礼的那只，`home: true`）。
2. **其他 11 只是「常客」**：锅里煮上它爱吃的（或节气点心，谁都爱吃），它就从屏幕边上走进来（排着队、一只一只，见 pot 设计的「进场排队」），吃一口，然后在营地里该干嘛干嘛（散步、和家具玩、睡觉、说话，和住户一样；能喂、能点）。
3. **锅里一样吃的管 8 小时**（`POT_STAY_MS`）：最后一样下锅过了 8 小时，锅就空了、火熄了。锅空了，没住下的常客就走（从最近的一边走出屏幕，提示条「🍲 锅里空空的，糯糯、杞杞回家了，放点它们爱吃的就回来」）。一天仍然最多放 3 样（按下锅那天算），锅里同一样不能放两份。
4. **亲密度**（`fed`，等级 `LEVELS` 不变：0 / 3 / 8 / 15 / 25）：它爱吃的下锅、它来吃 +3（节气点心 +5）；直接喂 +3 / 不爱吃 +1 / 点心 +5；拍正餐时在场的全员 +1（每天最多 3 次）。第一次来也算一顿。
5. **5 级就住下**（`HOME_LEVEL`，`home: true`）：锅空了也不走。住下的那一刻营地里提示「🎉 糯糯住下啦，以后不走了」、大家围着火蹦一蹦；拍正餐时升到 5 级的，结果页横幅「糯糯住进营地啦」。
6. 12 只都来过 → 金色秋千（照旧，在下锅引来第 12 只时送）。

节奏估算：一只常客它爱吃的一天煮一次（+3）+ 拍三顿（+3）≈ 每天 +6，四五天住下；只靠煮也就八九天。

## 数据（`camp: 5`）

- `pets[]: { id, since, fed, fedToday, home, until }`。`until` = 这只常客能待到几点（毫秒时间戳，= 最近一次锅的到期时间）。**在场** = `home || until > now`。来过没住下、这会儿不在场的还留在 `pets` 里（亲密度记着），再煮它爱吃的就回来。
- `pot: { items: [{ foodId, at, date }] }`。在煮的 = `now - at < POT_STAY_MS`；锅的到期 `until` = max(at) + 8h。view 给页面 `pot: { foods, until }`。
- 去掉 `visitors`、`arrivals`。迁移：客人变成常客（`until` = 锅到期，锅空就 0）；老住户 `home` = 豆豆或 5 级，其余 `until` = 锅到期（锅空着的，迁移完就不在场，下次煮它爱吃的再来）；`pot.date / foods` 是今天的就当刚下锅。

## 云函数（`services/camp.js`）

- `putFood`：在场、爱吃的 `eaters` 过来吃（+gain）；**来的** `comers` = 今日菜单里这样的 ∪ 来过、爱吃它的，去掉在场的（第一次来的加进 `pets`）；在场的常客和来的 `until` 都刷新成锅到期；跨到 5 级的 `movedIn`。返回 `cooked: { foodId, eaters, comers, movedIn }`。
- `feed`：只能喂在场的（不在场报「它这会儿不在营地」）；返回 `movedIn`。
- `arrive`（拍正餐）：在场的全员 +1；返回 `movedIn`（结果页横幅），没有就 null。不再让谁「住下」。
- `get`：`pets` 只有在场的（带 `home`）、`met` 是来过的 id（背包头像亮不亮）、`pot.until`。
- `gift`：送礼的从在场、4 级以上里挑。`album`：`met`（来过）/ `home`（住下了）分开。

## 页面

- 锅到期：页面每分钟的那次检查里，`pot.until` 过了就把锅清空、火熄掉、重画（不用等下次进营地）；常客的 `leaving` 跟着触发。
- `camp-life`：没有「客人」这种状态了（都是住户的行为，能喂、能点、会睡）；`leaving(a)` = 锅空着且没住下；`addGuest` 取代 `addVisitor`（在场的不加，走了的重新排队回来）；下锅后排队回来的只听云函数的 `comers`。
- **少待在锅边**：开局随机站在草地上（三成在火边）；早上不再每回合都去火边（三成）；饿着等的机会 0.3 → 0.2；吃完就该干嘛干嘛。
- 说话：常客（没住下）会说「再喂我几顿，我就搬来住」一类（`pet-talk.js` 的 `STAY`）；「你拍正餐我就住下」删了。
