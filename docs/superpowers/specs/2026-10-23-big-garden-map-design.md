# 大地图庭院 + 去掉每日的树 — 设计文档

日期：2026-10-23 · 状态：已确认 · 修改：[养生庭院 + 扭蛋机](2026-10-23-garden-gacha-design.md)（庭院大小、扩地方式）、[养生森林](2026-10-22-forest-reward-design.md)（每日的树不再显示）、[庭院小动物](2026-10-23-garden-animals-design.md)（走动范围）

## 目标

1. 庭院从「一小块地」变成像小程序页游那样撑满屏幕的大地图：一指拖动、双指缩放，丝滑；一开始只有中间一块地，周围是荒地，花暖豆一块块开荒扩建。
2. 去掉「每日的树」：奖励只留一条线——打卡得暖豆 → 扭蛋 → 摆放 → 引来小动物。今日页、打卡结果页、打卡日历改成「打卡印章 + 暖豆」。

## 规则

### 地图与开荒

- 地图是 3×3 块地，每块 6×6 格，合起来 18×18 格。格子坐标 (c, r) ∈ [0, 18)；块坐标 (pc, pr) = (⌊c/6⌋, ⌊r/6⌋)，用 `"pc,pr"` 表示，中间一块是 `"1,1"`。
- 一开始只开垦 `"1,1"`。其余 8 块是荒地。
- 只有和已开垦的地**上下左右相邻**的荒地能开荒；开荒价格按已开垦块数递增：第 n 次开荒（已开垦 n 块时）花 `100 + 50 × (n − 1)` 暖豆，即 100、150、200……450，全部开完共 2200。
- 暖豆不够：提示「暖豆不够啦，开荒要 X 暖豆，再攒攒」。不相邻：「要挨着已经开垦的地才能开荒」。已开垦：「这块地已经开垦过了」。不在地图里：「这块地不在庭院里」。
- 物件只能摆、移到已开垦的地上（「这块地还没开荒呢」）。小动物也只在已开垦的地上走。
- 取消「图鉴集齐 20 种庭院变 8×8」；扭蛋结果不再有「庭院扩大」。
- 新手礼的大树种在地图正中 (8, 8)。

### 旧数据

`gardens` 文档没有 `plots` 字段时，视为旧的小庭院坐标：所有已摆物件的 c、r 各加 6（落进中间一块）；`plots` = `"1,1"` 加上这些物件所在的块（原来 8×8 庭院里第 7、8 行列的东西会落到相邻块，那几块直接算开垦，不花暖豆）。保存时写入 `plots`，以后不再迁移。

### 每日暖豆（不再显示树）

- 暖豆规则不变：当天三顿正餐的打卡情况决定当天暖豆（打卡 1 顿 10、2 顿 20、3 顿 40、3 顿且 2 顿绿色 50、3 顿全绿 60），加餐不算。内部仍用 `dayTree` 算档位，界面上不再出现「树」。
- 打卡印章：每天早 / 午 / 晚三个印章，取每种正餐最新一次打卡：绿色评级 `green`、黄色 `yellow`、红色 `red`、分析失败但打了卡 `done`、没打卡 `none`。
- 提示语（按当天档位）：
  - 没打卡：「打卡一顿正餐就能得 10 暖豆」
  - 打卡 1～2 顿：「再打卡{下一顿}还能得 {差额} 暖豆」（下一顿按现有 `nextMissingMeal` 规则）
  - 3 顿、绿色不到 2 顿：「三顿都打卡啦！明天多吃绿色的，暖豆更多」
  - 3 顿、2 顿绿色：「真棒！明天三顿都吃成绿色，能拿满 60 暖豆」
  - 3 顿全绿：「三顿都吃得好，今天的暖豆拿满啦！」
- 今日页卡片：标题「今天得了 {N} 暖豆」（没打卡时「今天还没打卡」），一排三个印章，提示语，「🔥 已连续 X 天」。点卡片去庭院。
- 打卡结果页横幅：标题「+{这次多得的暖豆} 暖豆」（这次没多得时「这顿记下啦」），一排印章，提示语。
- 打卡日历：每天格子里是日期 + 三个小印章 + 当天暖豆数（没有就不写）；顶部卡片同今日页卡片；月底一行「这个月打卡 X 天，得了 Y 暖豆」。连续天数照旧。

## 庭院页面

### 布局（全屏）

- 庭院页去掉标题栏（自定义导航），只保留底部 tab 栏；地图铺满其余整个屏幕。
- 地图用小程序自带的可拖动、可缩放区域：一指拖动带惯性，双指缩放 0.5～1.5 倍，不能拖到完全看不见小岛。
- 1 倍时中间一块地正好占满屏幕宽度；第一次进来居中显示中间一块，四周能看到荒地边缘。
- 屏幕上浮着的按钮（避开手机状态栏和右上角胶囊按钮）：
  - 左上：暖豆数；胶囊下方右侧：「图鉴 x/48」；其下依次是节气限定提示、「有小动物在院子外张望」提示。
  - 底部一排圆按钮：扭蛋机、背包、打卡日历；右侧一个小按钮「回到中间」。
- 背包是从底部滑上来的抽屉：横向列出物件，点一个就收起抽屉、进入摆放模式（已开垦的空格高亮），底部出现「摆放「X」：点一块亮着的空地 · 取消」。点已摆物件仍是「移动位置 / 收回背包」。

### 地面与外观

- 每块地一张地面图：已开垦是现在的浅深相间草地；荒地是深一些的草地，有杂草丛和小石头。每块图都带下面的土边，按从后往前的顺序画，内部的土边被前面的地盖住，只有小岛外圈露出土边。
- 能开荒的荒地中间立一块木牌「开荒 · X 暖豆」，轻轻摇晃；点木牌弹出「花 X 暖豆开垦这块地？」，确认后杂草淡出、冒一团尘土，变成草地。不能开荒（不相邻）的荒地没有木牌。
- 小岛外面是由绿到浅米色的渐变背景，零星画几棵树、石头、云朵当装饰（不能点）。
- 先用脚本画的图；另给用户一份 Codex 出图说明（荒地杂草、木牌、尘土、外围树石云、背包和日历图标），出图后像上次一样切图替换。

### 小动物

- 只在已开垦的地上走；荒地对它们来说和摆了东西的格子一样走不进去。
- 新住户从已开垦土地的边缘走进来（从挨着荒地或地图边的那圈格子外面进来）。
- 开荒后页面重新安排（动物位置也重新随机）。

## 测试

- shared：块坐标、相邻、开荒价格、`tileOpen`；`mealStamps`、`beansHint` 各档位。
- garden service：开荒成功扣豆、各种失败、价格递增；摆放 / 移动到荒地被拒；新手大树位置；旧坐标迁移（含落到相邻块自动开垦）。
- forest service / meal service：印章、暖豆、提示语、日历统计；`gain` 字段。
- 端到端：攒豆 → 开荒 → 摆到新地上 → 小动物搬来。
- `utils/world.js`：布局尺寸、地面图顺序、屏幕点在拖动 / 缩放后仍换算到正确的格子。
- `garden-life`：不走进荒地；新住户从开垦土地边缘进来。
- 页面：庭院全屏渲染、背包抽屉、摆放、开荒确认、回到中间；今日页 / 结果页 / 日历的印章和文案；扭蛋页、图鉴页不再提扩大。

## 不做（YAGNI）

更大的地图（5×5 块）、拖拽摆放物件、旋转物件、多格物件、地块主题（比如水田、竹林）、开荒倒计时。
