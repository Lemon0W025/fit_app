# 小动物说话 — 设计文档

日期：2026-10-27 · 状态：用户嫌小动物只会说「好香啊」太贫乏，要每只有自己的特点、说可爱的话、跟妈妈互动（「你今天吃了多少？我也要向你学习」）、
说食物小知识。用户说「你先做一把，等我回来再看效果、看哪里要改」，所以这是第一版，台词都在 `miniprogram/utils/pet-talk.js`，改起来只动这一个文件。

## 什么时候说

- **点它**：说一句（睡着的照旧先醒：「嗯…？醒啦」；吃着东西说「小米最香了」那句）。
- **自己开口**：每隔 15～28 秒，挑一只醒着、闲着、头上没气泡的住户说一句，留 4.5 秒；同时只有一个气泡（它们之间的小事除外）。
- **客人**：闻着香味来的说它闻着什么（「咦！是竹笋的香味！」），不再只说「好香啊」。

## 说什么（按分量随机，同一只不连着说同一句）

| 类 | 分量 | 例子 |
|---|---|---|
| 自己的碎碎念 | 3 | 每只 8 句新的 + 原来的 8 句，见下表 |
| 聊今天打卡 | 3 | 该吃午饭啦，记得拍一张给我看；今天拍了 2 顿啦，真棒！；你今天吃了 900 千卡，还能吃 340，我也要向你学习！；吃多了劝饭后散步；三顿都准时夸；连续打卡 N 天；锅里煮着什么 |
| 爱吃的食物小知识 | 2 | 我最爱小米！小米粥养胃，早上来一碗最合适（用图册里那句 tip） |
| 养生小提示 | 1 | 先吃菜，再吃肉，最后吃主食；晚饭七分饱，夜里睡得香…… |
| 撒娇（亲密度 3 级起） | 1 | 你来啦！我好想你；（小声）最喜欢…你了；哼…才不是想你了 |
| 早上好 | 1（只在早上） | 原来的 morning 那句 |

聊今天打卡用的是营地拿到的今天的情况：早午晚印章（拍了没、准时没）、连续天数、饭点（`camp.get` 的 `daily`），
和今天吃了多少、一天的预算（`camp.get` 新加的 `intake`）。不知道就不聊这一类。

## 每只的口气

同一类话按口气套不同的说法：活泼（豆豆、柿柿、杞杞、薯薯、笋宝）、小声害羞（糯糯、茶茶）、慢悠悠（莲莲、龟龟、鹤鹤）、傲娇（花花）、懒洋洋（橘团）。

| 宠物 | 口气（性格） | 碎碎念举例 |
|---|---|---|
| 豆豆 | 活泼（话痨，啥都好奇） | 叽！你看那朵云，像个馒头；叽叽，我今天数了十只蚂蚁；我长大了也要会拍照！；你闻到了吗？锅里好香 |
| 糯糯 | 小声害羞（胆小，爱躲） | （小声）今天…你来啦；我、我刚才没有躲，真的；你的手…暖暖的；风好大…耳朵要飞了 |
| 莲莲 | 慢悠悠（慢性子） | 嘎～今天也慢慢来；晒晒太阳，啥都不想；荷叶上的露水，可甜了；嘎，吃饭不用急 |
| 柿柿 | 活泼（勤快，爱搬东西） | 嘿咻，搬完这根就歇；我给营地扫了扫落叶；柿子要放软了才甜；勤快一点，身体好 |
| 花花 | 傲娇（傲娇） | 哼，才不是在等你；本喵今天心情还行；尾巴上的花，好看吧；…你今天来晚了 |
| 龟龟 | 慢悠悠（爱晒太阳） | 慢…慢…晒…太阳；我的苔藓…又绿了；着急…会…噎着；走…慢点…不累 |
| 杞杞 | 活泼（机灵，爱恶作剧） | 嘿嘿，我把薯薯的核桃藏起来了；你猜我项链上有几颗枸杞；偷偷告诉你，糯糯怕打雷；嘿嘿，今天谁也没发现我 |
| 薯薯 | 活泼（贪吃） | （嚼嚼）你吃了吗？；我腮帮子能装三个核桃；吃饭要专心，像我一样；（嚼嚼）这个也好吃 |
| 橘团 | 懒洋洋（懒，只晒太阳） | 喵…晒太阳是正经事；别叫我，我在充电；你走走，我替你躺着；喵…今天也不想动 |
| 笋宝 | 活泼（呆萌） | 嗯？刚才谁叫我？；我的帽子…今天也很香；竹笋要慢慢嚼哦；嗯…我忘了要干啥了 |
| 茶茶 | 小声害羞（安静，爱听人说话） | 嗯，我在听你说；今天累不累？；慢慢说，不着急；花开了，你看到了吗 |
| 鹤鹤 | 慢悠悠（高冷，只在清晨出现） | ……早；晨光正好；站直，深呼吸；早起的人，有精神 |

## 气泡

- 单独一层、盖在所有东西上面（以前在宠物里面，走到锅、帐篷后面会被挡住）。
- 宽度按字数（一个字约 16px，最宽 230px），一般两行以内。
- 开口那一下夹在屏幕看得到的那段里、让开两边的按钮，之后跟着它走。

## 回来看效果时可以改的

- 每类的分量（`talkLine` 里的 w）、自己开口多勤（`camp-life` 的 `CHAT_MS`）、气泡留多久（`CHAT_BUBBLE_MS`）。
- 任何一句台词（`pet-talk.js` 的 `CHATTER` / `TODAY` / `FOOD_TIPS` / `HEALTH` / `AFFECTION` / `SNIFF`）。

## 10/28 第二版（用户看了第一版）

用户反馈：说得太勤；看不出是谁说的；话太长；锅里没吃的时候，不够亲的小动物应该先离开，亲密度够的留下来喊「好饿啊」。改成：

- **少说**：自己开口从 15～28 秒一次放慢到 45～90 秒一次（`CHAT_MS`）。
- **看得出是谁**：气泡左边是说话那只的头像，下面一个小尖角指着它；开口时它蹦一下；只挑站着不动的开口，说完之前不走开（点它说话也一样）。
- **话短**：每句 16 个字以内（多数 10 个字左右，一行放得下），爱吃的食物小知识换成短的（`SHORT_TIPS`），单测查长度。
- **锅里空着**（今天还没下锅）：3 级以下的说一句「我去找吃的啦」、走到营地边上藏起来（打开营地时就不在），
  3 级以上的和最亲的那只（营地不会一只都没有）留下来，常去锅边坐着等、喊饿（「好饿啊，好饿啊！」「肚子咕咕叫了！」）；
  营地顶上提示「🍲 锅里空空的，杞杞、薯薯找吃的去了，放点吃的就回来」；一下锅，走掉的陆续从营地边上回来（「闻到香味啦！」）先去锅边吃一口。
  「找它」里写「锅里空空的，找吃的去了」。叼礼物的是 4 级以上，不会走。
