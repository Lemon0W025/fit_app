## 一、新手指引

面向长辈：大字、一屏一件事、能跳过、不用学。

1. **欢迎页**（`pages/welcome/welcome`，自定义导航全屏）：还没建档时今日页先进这里（这次打开小程序只进一次，`globalData.welcomed`）。
   左右滑的四张大卡，下面圆点：
   - 「每顿饭，拍一张」：拍下来交给小暖，她帮你算热量、说说吃得好不好（相机图标）
   - 「饭点前后一小时，算准时」：准时拍得 15 暖豆，三顿都准时再加 15；到点手机会提醒你（暖豆 + 印章）
   - 「暖豆养小动物」：营地里煮一锅好吃的，小动物闻着香味就来住（全家福）
   - 「先花一分钟设好」：① 填身高体重（算每天吃多少）② 设饭点提醒 ③ 拍第一顿 →「开始」
   前三张底下「下一步」，右上「跳过」直接到第四张。「开始」去「我的」建档。
2. **建档以后**：第一次保存成功直接进「饭点提醒」页（`?first=1`），底下「设好了，去拍第一顿 ›」回今日页。
3. **今日页「新手三步」卡**（最上面）：✓ 建好档案、○ 设好饭点提醒（点了去提醒页）、○ 拍第一顿饭（点了去打卡）。三步都做了就不显示；
   右上「不用了」也能关（本地记住）。云函数 `day.get` 带 `guide: { remind, meal }`（提醒设过没有：加过日历或开了微信提醒；拍过没有：有任何一条打卡）。
4. **营地第一次进来**的欢迎卡改成三行大字步骤（背包里的吃的拖进锅里煮 → 爱吃的小动物闻香来、拍正餐就住下 → 点小动物会说话、暖豆买家具）。

## 二、饭点提醒

照准时打卡设计第二块：

- 新页面 `pages/remind/remind`「饭点提醒」（「我的」进，第一次建档后自动进）：三个饭点；「在手机日历里加三个饭点闹钟」（`wx.addPhoneRepeatCalendar`，每天重复、饭点那一刻响）；
  微信提醒开关（新控件 `components/switch`：弹性开关）+「还能提醒 N 次」。
- 微信服务通知要模板 ID：**云函数 `config.remindTemplate` 是空的时候，微信提醒那一块不显示**，只有日历闹钟。用户给了模板 ID 后填进去、`npm run wx:trigger` 建定时触发器。
- 数据、接口、发送规则、定时触发器照原设计（`reminders` 集合、`remind.*`、`lib/remind.js` 的 `planReminders`、每 10 分钟 `remind.tick`）。
- 打卡页点「交给小暖看看」时先 `wx.requestSubscribeMessage`（有模板时），允许了就攒一次。

## 三、几个人一起吃

- **拍照时**：打卡页「几个人一起吃？」一排：就我 / 2 人 / 3 人 / 4 人 / 5 人 / 更多（6～10 人）。默认「就我」。
  传给小暖：「5 个人一起吃：一盘一锅大家夹的菜，先估整盘，再按 5 份算她那一份；单独盛给她的（一碗饭、一碗汤）按她那一碗算」。
  每道菜 AI 标 `shared`（大家夹的 true，她自己那份 false）。打卡记 `people`。
- **结果页**：「吃了哪些」下面同样一排「几个人一起吃？」，点了 `meal.share { mealId, people }`：大家夹的菜按 原来人数 / 新人数 缩放
  （她单独改过的份量也按比例留着），自己那份不动；热量滚到新数。分着吃的菜写「一锅 · 你那份约 80 克」。
- **一道菜**：改份量的抽屉里多一排「这一盘我吃了：全部 / 一半 / 三分之一 / 四分之一 / 五分之一」（相对整盘：大家夹的菜整盘 = 现在 × 人数），
  上面那排快捷改成「少一点 / 原样 / 多一点 / 两倍」。
- 老打卡没有 `shared` 的菜当成大家夹的。
