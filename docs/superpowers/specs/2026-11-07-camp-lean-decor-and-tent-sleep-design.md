# 营地：家具精简、草坪花草、进帐篷睡（2026-11-07）

用户反馈（11/07 夜）：① 家具太多，而且小动物躺进吊床、坐上野餐垫这些会「穿模」，只留几样和草地完美贴合的；吊床、野餐垫、花坛明确去掉；② 家具种类暂时少一些，多设计一些能直接种在草坪上、不违和的花（比如一排向日葵）；③ 困了可以去露营的大帐篷里睡，趴着、只露一个小脑袋。

## 3. 进帐篷睡（`camp-life`、`shared/camp.js` 的 `SCENE.tent.beds`）

- 两个床位 `beds: [{ at, door }]`：`at` 是露出来的小脑袋下巴搁的地方（画上帐篷地板的前沿，从左下往右上斜着，约 (980,1387)→(1393,1287)，在帐篷禁区里），`door` 是进去前 / 出来后站的点（禁区外一点）。
- 困了（`drowsy`）：先想着帐篷——`TENT_CHANCE` 0.7、有空床位就走过去（再远也去，不受 `NAP_REACH` 限制），不然照旧找附近的窝 / 树荫 / 帐篷门口 / 原地趴下。到门口背对着我们站 0.6 秒（`TENT_IN_MS`），然后「放」到床位上，动作 `tent`：正面站着那帧（C 张 `idleFront`，没 C 张用待机 / 单张图），**裁掉下半截只露头顶往下 42%**（`TENT_SHOW`；按这只头顶在格里的位置 `top` 和脚 `FOOT` 算，内联样式 `tentStyle`：`clip-path: inset(0 0 N% 0); transform: translateY(M%)`，裁的边正好落在床位那条线上），没影子，冒 💤；排在它横着跨到的所有帐篷条前面（`depthY` = 那些条的 `zy` 最大值 + 4）。白天睡 45～120 秒（`TENT_NAP_MS`，比原地打盹久），夜里按 `NIGHT_NAP`。
- 出来：醒了、被点、被叫、要走之前都先 `leaveTentThen`：站回 `door`、面朝我们、这一帧不带过渡，**下一拍**（`SHOW_MS`）再做要做的（不然从床位直接过渡到第一个拐点会穿过帐篷布）。
- 切走再回来：`snapshot` 记 `action: 'tent'` + `until`，`restore` 没睡完接着趴在里面（不算草地检查），睡完了站在门口。
- 「找它」里写「在帐篷里睡觉」。
