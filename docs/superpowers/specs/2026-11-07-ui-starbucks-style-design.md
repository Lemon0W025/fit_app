# 界面美化：照 Starbucks 的设计系统（2026-11-07）

> **已被同一天的 `2026-11-07-ui-bento-design.md`（便当盒风格）取代**：用户觉得这版太简单、没有设计感。

用户让参考 [awesome-design-md](https://github.com/voltagent/awesome-design-md)（80 多个知名产品的 DESIGN.md 设计规范合集）选一个最合适的来美化界面。

## 为什么选 Starbucks

比了几套和「小暖」气质接近的：

| 候选 | 特点 | 合不合适 |
|---|---|---|
| **Starbucks** | 奶油色底、四档绿、金色只给会员积分 / 奖励、胶囊按钮、很淡的分层阴影、不用渐变 | **最合适**：奶油底 + 绿主色本来就是我们的底子（营地也是一片绿）；它的「星星积分」正好对上暖豆、印章、纪念章；面向所有年龄的大众消费 App，按钮大、对比强 |
| Oura | 健康戒指，暖纸色 + 编辑感衬线体 | 气质对，但靠衬线大标题撑，中文衬线字体要另外加载、长辈看着也累 |
| Claude | 奶油底 + 珊瑚色按钮，编辑排版 | 「暖」对得上，但珊瑚色和营地的绿冲 |
| Notion / Airbnb / Wise | 暖极简 / 珊瑚照片流 / 亮绿 | 要么太素、要么太年轻 |

## 色板（`app.wxss` 的 `page` 变量）

原来的变量名都留着（页面不用全改），值换成 Starbucks 的，另外加了几个：

| 变量 | 值 | 管什么 |
|---|---|---|
| `--bg` | `#f2f0eb` Neutral Warm | 页面底色（不用纯白） |
| `--ceramic` | `#edebe9` | 分段控制器底槽、圆环底、小块底 |
| `--brand` | `#006241` Starbucks Green | 页面大标题、段落标题、大数字（热量、体重、饭点） |
| `--primary` | `#00754a` Green Accent | 按钮、链接、选中、圆环 |
| `--house` | `#1e3932` House Green | 深绿横幅（`.band`） |
| `--primary-soft` / `--primary-wash` | `#d4e9e2` / `#eaf4f0` | 浅绿底（新手三步、小暖说、选中的小块） |
| `--gold` / `--gold-light` / `--gold-wash` | `#cba258` / `#dfc49d` / `#faf6ee` | **只给奖励**：暖豆、准时「准」、纪念章、新住户 |
| `--gold-ink` | `#85631f` | 白底上的金色字（Starbucks 的金在白底上太浅，长辈看不清） |
| `--text` / `--muted` | 87% / 60% 黑 | 正文不用纯黑；次要字比 Starbucks 的 58% 深一点 |
| `--red` | `#c82014` | 删除、超了 |
| `--shadow-card` / `--shadow-float` | 两三层很淡的阴影叠起来 | 卡片 / 浮起来的圆钮和大按钮 |

## 组件规矩

- **按钮一律胶囊**（`border-radius: 999rpx`），按下缩到 0.95（`button-hover`、`chip-press`、`tag-press`、`seg-press`、导览「下一步」）；卡片 `fx-press` 缩到 0.97
- **深绿横幅 `.band`**：白字、次要字 78% 白；上面的按钮用 `btn-on-dark`（白底绿字）。用在：首页「下一顿」大卡、结果页的热量和营养素、点通知进来的那句「到晚饭时间啦」、建档欢迎卡。一页最多一块，是这页最要紧的那件事
- **奖励卡 `.reward-card`**：金色奶油底 + 一圈金边，标题 `--gold-ink`。用在：首页暖豆卡、结果页「+20 暖豆」和新住户、日历顶上的今天；营地摆放条、金色提示条也是这套
- **纪念章庆祝卡**：深绿底 + 金边 + 金色标题 + 白按钮绿字（Starbucks 会员等级卡的样子）
- **金色胶囊**（`.pill-gold`、首页的「🫘 准时拍能得 15 暖豆」）：金边、深色底上用 `--gold-light` 字
- **印章**：准时的金圈和角上的「准」是金底深绿字
- **不用渐变**：界面上的卡片、横幅、按钮都是纯色块。例外：纪念章本身（铜银金的金属感是「东西」不是界面）、营地的画和画里的光
- **段落标题**是 Starbucks Green、加粗，靠颜色和粗细分层次，不靠字号
- 中文不加 Starbucks 的 `-0.01em` 字距（中文字是方块，挤一点反而难认）；字号保持原来的大号（长辈）

## 营地

画（底图、宠物、装饰、火、光）一点不动。只改浮在画上的界面：

- 左上角暖豆余额：深绿胶囊 + 金边（像 Starbucks 的星星余额），不再是蓝色游戏条
- 两边圆钮：白底圆钮 + 两层浮起阴影（Starbucks 的「Frap」浮动按钮），字用深绿
- 底部「拍一拍这一餐」：Green Accent 纯色胶囊 + 浮起阴影，不再是亮绿渐变 + 3D 底边
- 提示条：白色胶囊；绿色的浅绿底；金色的金色奶油底 + 金边

## 其他跟着换的

- `app.json`：导航栏和窗口底色 `#F2F0EB`，tab 字 `#6B6B6B` / 选中 `#00754A`；tab 图标用 `scripts/draw-images.py` 的 `draw_tabs()` 重新画（`TAB_COLORS`）
- 体重曲线（`weight.js` 的 `CHART_COLORS`）、彩带（`utils/confetti.js`）、删除确认框的红色
- 组件（`segmented`、`sheet`、`slider`、`switch`、`ring`、`tour`、`celebrate`、`medal` 的绿丝带）里写死的旧颜色

## 以后加界面

先用变量，别写死颜色；金色只给奖励；要强调的一件事用 `.band`；不加渐变。
