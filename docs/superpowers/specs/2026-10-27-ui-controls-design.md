# 第一批控件：弹性抽屉、环形进度、分段控制器、商店标签筛选 — 设计文档

日期：2026-10-27 · 状态：用户看了「8 种控件交互」的灵感，同意先做这 4 个（「可以的」）；其余 4 个：滑杆等份量那块、开关等提醒那块，
自定义底部栏和搜索框不做（微信自带底部栏稳定不闪；小程序里没有要搜的东西）。

## 总原则

- 面向长辈：字号偏大、动效克制，只用来表示「状态变了」和「点到了」。
- 只动 `transform` / `opacity`（和颜色过渡）；快速连点不堆积、不闪，最后状态一定对（CSS 过渡被打断会从当前位置转向新目标）。
- 跟手的拖动（抽屉往下拉）用 WXS 直接改样式，不走每帧 setData。
- 动画结束的样子 = 平时的样子（和 `app.wxss` 现有的 `fx-*` 一致）；数字滚动用 `utils/fx.js` 的 `countUp`（定时器走 `this.clock`，测试注入 `manualClock`）。
- 小程序读不到系统的「减少动态效果」，这次不做开关；键盘 / 鼠标在手机上用不上，焦点样式不另做。
- 自定义组件放 `miniprogram/components/<名>/`，类名带前缀（`sheet-*`、`ring-*`、`seg-*`，预览渲染器没有样式隔离）；测试用 `page-harness` 的 `loadComponent`。

## 1. 弹性抽屉 `components/sheet`

- 用在营地的「背包」「住户」两个抽屉（`pages/camp`），替换现在手写的 `.drawer`。
- 属性：`show`（Boolean）、`title`（String，可空）；插槽放内容；事件 `close`（点遮罩、点 ✕、往下拉过一定距离都触发，由页面把 `show` 设成 false）。
- 打开：面板从下往上进来，冲过头一点再回弹（`transform: translateY`，约 420ms，`cubic-bezier(0.34, 1.4, 0.64, 1)`）；遮罩同时淡入（opacity 0 → 1，280ms）。
- 关闭：面板往下退（260ms ease-in），遮罩同步淡出；动画放完才真正不渲染（避免一下子消失）。
- 往下拖：按住顶部把手 / 标题栏往下拖，面板跟手（WXS），松手超过面板高度的 25% 或者速度够快就关，否则弹回；
  内容区是 scroll-view，内容区滚到顶以后再往下拉才算拖抽屉，滚动中不抢手势。
- 打开时遮罩 `catchtouchmove`，背后的营地拖不动（锁住背景）。
- 面板底部留出安全区（`env(safe-area-inset-bottom)`）。

## 2. 环形进度 `components/ring`

- 用在首页「今日」的热量卡（`pages/today`），替换「已吃 N 千卡」那根横条：圆环 = 今天吃了每日预算的多少，中间大字是已吃的千卡，下面一行「还能吃 M」或「超了 M」。
- 属性：`value`（已吃）、`max`（预算）、`size`（rpx）、`over`（超了变色）。
- 数字和圆环共用一个动画进度：从当前显示的值过渡到新值（不归零重播），先快后慢（ease-out cubic），约 800ms；0% 和 100% 都画得对，超过 100% 圆环画满、颜色换成提醒色。
- 圆环用两个半圆 + `rotate` 的做法（纯 CSS、只动 transform），不用 canvas。
- 首页现有的数字滚动（`playNumbers`）改成驱动这个组件，进度条那段样式删掉。

## 3. 分段控制器 `components/segmented`

- 用在：打卡页「这是哪一餐？」（早餐 / 午餐 / 晚餐 / 加餐）、我的页「性别」（女 / 男）、营地背包的「食物 / 装饰」。
- 属性：`options`（`[{ label, value }]`）、`value`；事件 `change`（`detail.value`）。
- 选中的底色是一块滑动的胶囊：点新选项时先朝移动方向拉长（盖住旧的到新的），再收到新选项的宽度（两段过渡：领头那边快、跟着那边慢一点，合起来约 320ms，带一点回弹）；
  用 `translateX` + `scaleX`（胶囊宽度按每个选项量出来的实际宽度，适配不同字数）。连续快点：总是从当前位置转向最新的目标。
- 文字颜色同步变（选中白字、没选中深灰）；按下缩到 0.96 再回来。

## 4. 商店标签筛选

- 商店顶上一排标签：全部 / 窝 / 吃喝 / 玩 / 花草 / 气氛（单选，默认全部），选中的只显示那一类（真的筛选，不是滚过去）。
- 没选中浅色底；选中主题绿实色底、白字；按下缩到 0.96 再回来；背景、文字、边框颜色 200ms 过渡。
- 全局的 `.chip` / `.chip-on`（打卡页以外别处还在用）一起改成同样的过渡和按压反馈。

## 测试和验收

- 组件：`sheet`（show 变化、点遮罩 / ✕ 触发 close、拖动阈值的判断函数）、`ring`（百分比和角度、超过 100%、从当前值继续、0 和满）、`segmented`（change、胶囊位置计算）。
- 页面：打卡页换餐次、我的页换性别、商店筛选、营地背包开关和切换、首页圆环的数值。
- `node scripts/preview/record-checkin.js` 录首页和打卡页，`node scripts/preview/record-camp.js` 录营地背包；`npm test` 全绿。
