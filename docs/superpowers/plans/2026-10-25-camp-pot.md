# 营地：食物下锅、夜里的灯、随机小睡、不瞬移、放大 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-10-25-camp-pot-design.md` 把营地改成「食物下锅点火 → 香味引来客人 → 下次拍正餐住下」，夜里火着全亮、火灭灯边暖亮，随机小睡可点醒，切回来不瞬移，小动物放大 1.3 倍。

**Architecture:** 云函数 `camp-state` 升到 `camp: 2`（`pot`、`visitors`，食盆 / 张望迁走），`services/camp` 改 `putFood` / `arrive`、删 `takeFood`；小程序 `camp-view` 换锅和客人的展示函数、删食盆，`camp-light` 加灯，`camp-life` 加客人 / 来吃的住户 / 随机小睡 / 快照 / 放大，营地页改拖放和点锅、存快照。共用文件（`shared/`）不改。

**Tech Stack:** 微信小程序、云函数（Node）、`node:test`、Playwright + ffmpeg 录屏。

## Global Constraints

- `npm test` 全绿再推；改动 JS 后跑 `node --check`
- `cloudfunctions/api/lib/shared/` 与 `miniprogram/utils/shared/` 逐字节一致（本计划不改它们）
- 云函数响应 `{ ok, data }` / `{ ok: false, code, message }`，message 中文、直接给用户看
- 错误文案：「锅里已经煮了三样啦，明天再放」「锅里已经有{名字}了，换一样吧」「背包里没有这个了」
- 提示条：「👀 糯糯闻着香味来了…下次拍正餐就住下」；点客人：「它闻着{食物}的香味来的。妈妈下次拍正餐，它就住下来」；客人头上「好香啊……」；点醒「嗯…？醒啦」
- 横幅：一只「糯糯闻着胡萝卜的香味，住进营地啦！」；几只「糯糯、笋宝住进营地啦！」
- 小睡：白天 6%、10～40 秒、同时最多 1/4（至少 1）；夜里（19～6 点）35%、1～5 分钟、最多 1/2；睡觉点离它 600 画像素内
- 灯：画上提灯 (2665, 2770) r 480、帐篷门口 (1210, 1460) r 520、摆的 `fx: 'glow'` 装饰 r 420（灯串 r 560）
- 火着：`brightness(0.92) saturate(1) sepia(0.12)`、月光层 0
- `PET_ZOOM = 1.3`
- 提交信息结尾两行 trailer（Co-Authored-By / Claude-Session），只推 `claude/mini-program-dev-nzn2n0`

`camp-state.js` 的 `normalizeCamp`：
```js
const CAMP_VERSION = 2
// camp 1 → 2：食盆里的退回背包，正在张望的变成客人（下次拍正餐住下）
function dropBowls(src) {
  if (!('bowls' in src) && !('peeking' in src)) return src
  const foods = { ...(src.foods || {}) }
  const bowls = src.bowls || []
  bowls.forEach((f) => { if (f) foods[f] = (foods[f] || 0) + 1 })
  const have = (src.pets || []).map((p) => p.id)
  const visitors = (src.visitors || []).slice()
  ;(src.peeking || []).forEach((id, i) => {
    if (id && have.indexOf(id) === -1 && !visitors.some((v) => v.id === id)) visitors.push({ id, foodId: bowls[i] || '', since: '' })
  })
  const out = { ...src, foods, visitors }
  delete out.bowls
  delete out.peeking
  return out
}
```
`normalizeCamp` 里 `const src = dropBowls(...)`，返回 `camp: CAMP_VERSION`、`pot: { date: pot.date || '', foods: pot.foods || [] }`、`visitors: (src.visitors || []).map((v) => ({ id: v.id, foodId: v.foodId || '', since: v.since || '' }))`；`adoptCamp` 返回 `camp: CAMP_VERSION`。

`services/camp.js`：
```js
const POT_MAX = 3
const potFoods = (camp) => (camp.pot.date === today() ? camp.pot.foods : [])
const likes = (petId, foodId) => { const f = foodById(foodId); return !!f && (!!f.term || petById(petId).foods.indexOf(foodId) !== -1) }
// view：pot: { foods: potFoods(camp) }, visitors: camp.visitors.map(({ id, foodId }) => ({ id, foodId }))，去掉 bowls
async putFood(openid, input) {
  const foodId = (input || {}).foodId
  const camp = await load(openid)
  const cooking = potFoods(camp)
  const food = foodById(foodId)
  if (food && cooking.indexOf(foodId) !== -1) throw new AppError(CODES.BAD_REQUEST, `锅里已经有${food.name}了，换一样吧`)
  if (food && cooking.length >= POT_MAX) throw new AppError(CODES.BAD_REQUEST, '锅里已经煮了三样啦，明天再放')
  takeFromBag(camp, foodId)
  camp.pot = { date: today(), foods: cooking.concat(foodId) }
  const eaters = camp.pets.filter((p) => likes(p.id, foodId)).map((p) => p.id)
  camp.pets = camp.pets.map((p) => (eaters.indexOf(p.id) !== -1 ? { ...p, fed: p.fed + feedGain(p.id, foodId) } : p))
  const visitor = arrivalFor(foodId, residentIds(camp).concat(camp.visitors.map((v) => v.id)), random())
  if (visitor) camp.visitors = camp.visitors.concat({ id: visitor, foodId, since: today() })
  await repo.saveGarden(openid, camp)
  return view(camp, { cooked: { foodId, eaters, visitor: visitor || null } })
}
async arrive(openid) {
  const camp = await load(openid)
  feedAll(camp)
  const comers = camp.visitors.filter((v) => !camp.pets.some((p) => p.id === v.id) && petById(v.id))
  camp.pets = camp.pets.concat(comers.map((v) => ({ id: v.id, since: today(), fed: 0, fedToday: { date: '', n: 0 } })))
  camp.arrivals = camp.arrivals.concat(comers.map((v) => v.id))
  camp.visitors = []
  if (isFull(camp) && !camp.decor.owned[GOLD_TENT]) camp.decor = { ...camp.decor, owned: { ...camp.decor.owned, [GOLD_TENT]: 1 } }
  await repo.saveGarden(openid, camp)
  if (!comers.length) return null
  return { pets: comers.map((v) => { const f = foodById(v.foodId); return { id: v.id, name: petById(v.id).name, foodId: v.foodId, foodName: f ? f.name : '' } }) }
}
```

```js
const LAMPS = [{ x: 2665, y: 2770, r: 480 }, { x: 1210, y: 1460, r: 520 }]
const LAMP_R = { lights: 560 }
function lampsOf(placed) { return LAMPS.concat((placed || []).map((p) => ({ p, d: decorById(p.id) })).filter((x) => x.d && x.d.fx === 'glow').map(({ p }) => ({ x: p.x, y: p.y, r: LAMP_R[p.id] || 420 }))) }
function lampAt(x, y, lamps) { return lamps.reduce((m, l) => Math.max(m, 1 - (dist / l.r)²), 0) 夹到 0..1 }
// nightLook：lit → 固定；不 lit → 先算 _OFF 那套，再 f = lampAt 往暖亮拉：b += (0.9 - b) f，saturate += (0.95 - s) f，sepia += (0.25 - sep) f，moon *= 1 - f
```
